윈도우 검색창에 글자가 안 쳐질 때 — "어디까지 안 되나"로 네 갈래를 가릅니다

2026년 11월 13일 · 2026년 11월 13일 갱신

시작 버튼을 누르고 프로그램 이름을 치는데, 검색창에 글자가 하나도 안 들어갑니다. 작업 표시줄의 검색창을 눌러도 마찬가지입니다. 키보드가 고장 났나 싶지만, 대부분은 키보드가 아니라 검색창 쪽 프로그램이 멈춘 경우입니다.

처방은 "어디까지 입력이 안 되나"에 따라 달라집니다. 그걸 가르는 도구는 메모장 하나면 됩니다.

결론부터

정황갈래먼저 할 것
검색창만 안 됨, 메모장·브라우저는 됨검색·탐색기 멈춤작업 관리자에서 검색 · 탐색기 다시 시작
검색창·설정·시작 메뉴 등 윈도우 입력창 전체가 안 됨, 메모장은 됨입력기가 빠짐다시 로그인 · 입력기 다시 띄우기
글자는 들어가는데 결과가 안 나오거나 엉뚱함검색 색인검색 문제 해결 도구 · 색인 다시 만들기

먼저 — 메모장에서 쳐 봅니다

메모장을 열어(시작 메뉴가 안 되면 Win + R → notepad → Enter) 아무 글자나 쳐 봅니다.

  • 메모장에서 된다 → 키보드는 무죄입니다. 검색창이나 윈도우 쪽 문제입니다
  • 메모장에서도 안 된다 → 키보드나 연결 쪽입니다 — 맨 아래 갈래 ④

메모장에서 된다면, 이번엔 설정 앱의 검색칸에도 쳐 봅니다. 여기까지 되면 갈래 ①, 여기도 안 되면 갈래 ②입니다.

갈래 ① — 검색창만 멈췄다

다른 곳은 다 되는데 시작 메뉴·작업 표시줄의 검색창만 안 된다면, 검색창을 그리는 프로그램이 멈춘 것입니다. 재부팅해도 풀리지만, 더 빠른 길이 있습니다.

  1. Ctrl + Shift + Esc로 작업 관리자를 엽니다
  2. 목록에서 검색(윈도우 버전에 따라 이름이 조금 다릅니다) 항목이 보이면 골라 작업 끝내기 — 검색창을 다시 열면 새로 뜹니다
  3. 그래도 안 되면 Windows 탐색기를 골라 다시 시작 — 작업 표시줄이 잠깐 사라졌다 돌아옵니다

작업 표시줄·시작 버튼이 클릭조차 안 먹는 쪽이라면 같은 처방의 다른 얼굴입니다 — 커서는 움직이는데 클릭이 안 될 때의 탐색기 갈래.

갈래 ② — 윈도우 입력창 전체에서 입력기가 빠졌다

메모장이나 브라우저 주소창은 되는데, 검색창·설정·시작 메뉴처럼 윈도우가 그리는 입력창 에서만 전부 안 된다면 그 입력창들에 글자를 넘겨 주는 입력기가 빠진 경우가 많습니다. 한글 입력과 관계된 부분이라, 이럴 땐 한영 전환도 같이 이상한 경우가 흔합니다.

  • 로그아웃했다 다시 로그인하면 입력기가 새로 뜹니다 — 재부팅보다 빠릅니다
  • Win + R → ctfmon → Enter로 입력기를 직접 다시 띄우면 풀리는 사례가 있습니다
  • 큰 윈도우 업데이트 직후부터라면, 업데이트를 마저 설치하고 다시 시작하는 것이 순서입니다

글자가 들어가긴 하는데 치는 족족 지워지는 쪽이라면 입력기의 다른 증상입니다 — 글자가 지워질 때.

갈래 ③ — 글자는 되는데 결과가 안 나온다

검색창에 글자는 들어가는데 아무것도 안 찾아지거나, 분명 있는 파일·프로그램이 안 나온다면 입력이 아니라 검색 색인(찾기 쉽게 미리 만들어 둔 목록) 쪽입니다.

  • 설정에서 검색 및 인덱싱 문제 해결 도구를 실행합니다(메뉴 위치는 버전에 따라 다릅니다)
  • 그래도 안 되면 색인 옵션에서 색인을 다시 만들기를 합니다 — 파일이 많으면 다 만들어질 때까지 시간이 걸리고, 그동안은 결과가 덜 나오는 게 정상입니다

갈래 ④ — 어디서도 입력이 안 된다

메모장에서도 안 된다면 검색창 탓이 아닙니다. 키보드 연결(포트·수신기·배터리)부터, 일부 키만인지 전부인지로 가르는 순서가 일부 키가 안 될 때에 있습니다.

자주 묻는 질문

영어는 쳐지는데 한글만 안 쳐져요

갈래 ②의 입력기 쪽일 가능성이 높습니다. 다시 로그인이나 입력기 다시 띄우기를 먼저 해 보고, 한영키 자체가 안 먹는다면 일부 키가 안 될 때의 FAQ를 봅니다.

검색창을 누르면 아예 안 열려요

입력 이전에 검색창 자체가 멈춘 것이라 갈래 ①과 같은 처방입니다 — 작업 관리자에서 검색 항목을 끝내고, 안 되면 Windows 탐색기 다시 시작.

매번 재부팅하면 풀렸다가 또 그래요

반복된다면 윈도우 업데이트를 끝까지 설치했는지, 탐색기에 끼어드는 프로그램(우클릭 메뉴 추가, 클라우드 동기화 등)을 최근에 깔았는지 봅니다. 그 프로그램을 잠시 꺼서 멎으면 범인입니다.

정리

  1. 메모장에서 쳐 보면 키보드인지 윈도우인지가 갈립니다
  2. 검색창만 → 작업 관리자에서 검색 끝내기 · 탐색기 다시 시작
  3. 윈도우 입력창 전체(설정·시작) → 입력기 — 다시 로그인 · ctfmon
  4. 글자는 되는데 결과만 → 검색 색인 문제 해결 · 다시 만들기
  5. 어디서도 안 되면 키보드 쪽 층 가르기로

입력의 이웃 판정들 — 클릭이 안 될 때 · 글자가 지워질 때 · 일부 키가 안 될 때와 이어집니다.

기준이나 동작이 실제와 다르면 알려주세요. 확인 후 갱신합니다.

같이 보면 좋은 글

  • 노트북 키보드 누를 때마다 삑 소리가 날 때 — 어느 키에서 나는지가 켜진 기능을 알려 줍니다 키를 누를 때마다 컴퓨터에서 삑 소리가 납니다. 고장이 아니라 윈도우 접근성 기능 셋 중 하나가 켜진 경우가 대부분이고, 어느 키에서 소리가 나는지로 어떤 기능인지 가릴 수 있습니다. 끄는 법과 실수로 다시 켜지지 않게 하는 법을 정리했습니다.
  • 노트북 더블클릭하면 속성 창이 열릴 때 — 마우스가 아니라 Alt 키가 눌린 채로 잡혀 있습니다 파일을 더블클릭했는데 열리지 않고 속성 창이 뜹니다. 고장처럼 보이지만 윈도우가 Alt 키를 누르고 있는 것으로 알고 있는 상태인 경우가 대부분입니다. 같은 원리로 생기는 Ctrl·Shift·Win 키의 형제 증상과, 눌림을 푸는 순서를 정리했습니다.
  • 노트북 타자 치면 글자가 지워질 때 — 어떻게 지워지는지 보면 범인이 셋으로 갈립니다 글을 쓰는데 뒤에 있던 글자가 하나씩 사라지거나, 스페이스를 누르면 방금 쓴 마지막 글자가 없어지거나, 손대지 않았는데 글자가 지워집니다. 지워지는 모양에 따라 덮어쓰기 모드, 한글 입력기, 키 자체의 문제로 갈립니다. 갈래별 확인 순서를 정리했습니다.
