바탕화면 아이콘이 다 사라졌을 때 — 사라진 범위가 갈래를 알려줍니다

2026년 9월 6일

컴퓨터를 켰는데 바탕화면이 텅 비어 있습니다. 몇 년치 폴더와 파일들이 다 있던 자리인데요. 심장이 내려앉고, "복구 프로그램"을 검색하게 되는 순간입니다.

검색 전에 심호흡 — 대부분의 경우 파일은 그대로 있고, 보이지만 않는 상태입니다. 그리고 어디까지 사라졌는지(아이콘만? 파일도? 작업표시줄도?)가 원인을 그대로 알려줍니다.

결론부터

사라진 범위유력 갈래
아이콘만 안 보임 — 폴더에는 파일이 있음표시 체크 해제 — 1분짜리 설정 문제입니다
아이콘도, 폴더 속 파일도 없음위치·계정 갈래 — OneDrive·다른 계정을 봅니다
작업표시줄까지 같이 사라짐탐색기(explorer) 층 — 프로세스 재시작입니다
아이콘은 있는데 위치가 뒤섞임해상도·모니터 구성 변경의 재배치 — 절전 창 몰림의 이웃입니다
바로가기 몇 개만 가끔 사라짐정리 동작·동기화 갈래입니다 (아래 FAQ)

판정 1분 — 폴더부터 열어 보세요

파일 탐색기를 열고 왼쪽에서 바탕 화면 폴더를 클릭합니다.

  • 파일들이 다 있다 → 실물은 무사합니다. "보여 주기"만 꺼진 것이니 아래 갈래 ①로 — 오늘의 놀람은 여기서 끝나는 경우가 대부분입니다
  • 폴더도 비어 있다 → 표시가 아니라 위치의 문제입니다. 갈래 ②로

갈래 ① — 표시 스위치: 우클릭 세 번

바탕화면 빈 곳 우클릭 → 보기 → "바탕 화면 아이콘 표시". 체크가 꺼져 있으면 켜는 순간 전부 돌아옵니다.

이 스위치는 마우스가 미끄러진 우클릭 한 번으로도 꺼질 수 있는 자리라, "내가 뭘 잘못했지?"를 오래 고민할 필요가 없는 갈래입니다. 가족·동료 컴퓨터에서 걸려 오는 전화의 단골이기도 합니다.

갈래 ② — 위치와 계정: 바탕화면이 이사 갔을 때

폴더까지 비어 있다면, 파일이 지워졌다기보다 바탕화면이라는 폴더의 위치가 바뀌었거나 다른 곳을 보고 있는 경우가 흔합니다.

  1. OneDrive부터 — 폴더 백업(동기화) 기능이 켜지면 바탕 화면의 실제 위치가 OneDrive 쪽 폴더로 옮겨집니다. 동기화 상태가 바뀌거나 로그아웃되면 바탕화면이 비어 보일 수 있습니다 — OneDrive의 바탕 화면 폴더를 열어 보면 파일들이 거기 살아 있는 경우가 많습니다
  2. 로그인 계정 확인 — 컴퓨터에 계정이 여럿이면, 다른 계정 으로 로그인된 상태의 바탕화면은 당연히 다른 내용입니다. 시작 메뉴에서 지금 계정 이름을 확인하세요
  3. 검색으로 실물 추적 — 기억나는 파일명 하나를 탐색기 전체 검색으로 찾으면, 파일들이 어느 폴더로 가 있는지가 드러납니다
  4. 여기까지 다 비었을 때에야 휴지통과 삭제 갈래를 봅니다 — 그리고 이런 날을 위한 보험이 백업 두 벌이라는 게 이 사건의 교훈입니다

갈래 ③ — 작업표시줄까지 없음: 탐색기 층

아이콘만이 아니라 작업표시줄·시작 버튼까지 통째로 없다면, 바탕화면을 그리는 프로그램(탐색기, explorer) 자체가 멈춘 상태입니다.

  • Ctrl+Shift+Esc로 작업 관리자를 열고 → Windows 탐색기를 찾아 → 다시 시작. 화면이 한 번 깜빡이며 바탕화면이 다시 그려집니다
  • 작업 관리자 목록에 탐색기가 아예 없으면, 파일 → 새 작업 실행에서 explorer를 입력해 직접 띄웁니다
  • 이게 자주 반복되면 단발 사고가 아니라 누적·상태 갈래라, 다시 시작(재부팅)과 업데이트 확인이 다음 순서입니다

자주 묻는 질문

아이콘 위치가 재부팅할 때마다 뒤섞여요

사라짐이 아니라 재배치 갈래입니다 — 해상도·모니터 인식이 바뀌는 순간 윈도우가 아이콘을 다시 줄 세우는 것으로, 절전 후 창 몰림과 같은 뿌리입니다. 그 글의 완화책(끄기 시간 일치 등)이 아이콘에도 통합니다.

바로가기 몇 개만 가끔씩 사라져요

전부가 아니라 바로가기만, 주기적으로라면 다른 갈래입니다 — 연결이 끊긴(대상이 없는) 바로가기를 시스템 정리 기능이 치우던 동작이 있던 버전이 있고, 동기화 도구가 정리하는 경우도 있습니다. 사라지는 게 늘 "죽은 바로가기"인지 확인해 보면 이 갈래인지가 갈립니다.

새로 고침을 눌러도 안 나타나요

새로 고침은 그리기를 다시 하는 것이지 표시 설정을 바꾸는 게 아닙니다 — 갈래 ①의 체크가 꺼져 있으면 새로 고침 백 번에도 안 나옵니다. 우클릭 → 보기부터 확인하세요.

파일이 진짜 지워진 것 같아요

휴지통 → 탐색기 검색 → OneDrive 휴지통(쓰는 경우) 순서로 확인하고, 거기 없으면 그때가 복구를 고민할 시점입니다 — 이때 하드에 새 파일을 쓰지 않는 것 이 복구 확률을 지키는 원칙입니다(빈자리에 덮어써지니까요).

게임하다 나오면 아이콘이 흐트러져 있어요

전체화면 게임이 해상도를 바꿨다 돌아오는 과정의 재배치입니다 — 게임 쪽 해상도를 바탕화면과 같게 두면 줄어드는 계열이고, 구조는 위 재배치 FAQ와 같습니다.

정리

  1. 놀라기 전에 폴더부터 — 탐색기의 바탕 화면 폴더에 파일이 있으면 실물은 무사한 겁니다
  2. 대부분은 우클릭 → 보기 → 바탕 화면 아이콘 표시 체크 한 번으로 끝납니다
  3. 폴더도 비었으면 OneDrive·계정·검색 순서 — 지워진 게 아니라 이사 간 경우가 흔합니다
  4. 작업표시줄까지 없으면 탐색기 재시작 — 작업 관리자에서 1분입니다
  5. 진짜 삭제로 확인되면 그때가 복구 고민 시점 — 그리고 교훈은 백업입니다

화면 표시의 이웃 판정들 — 절전 후 창·아이콘 몰림 · 오래 켜두면 느려짐(탐색기 층 반복 시) · 백업 전략과 이어집니다.

기준이나 동작이 실제와 다르면 알려주세요. 확인 후 갱신합니다.

같이 보면 좋은 글

  • 모니터 유튜브는 나오는데 게임 소리만 안 날 때 — 소리는 앱마다 따로 배선돼 있습니다 전체 소리는 멀쩡한데 특정 게임이나 프로그램만 조용한 증상은 고장이 아니라 배선 문제인 경우가 대부분입니다. 윈도우가 앱마다 볼륨과 출력 장치를 따로 기억하기 때문인데, 그 장부를 여는 순서와 헤드셋을 꽂았다 뺀 뒤 생기는 전형적인 함정까지 정리했습니다.
  • 모니터 절전에서 깨면 창이 한쪽 모니터로 몰릴 때 — 모니터가 잠깐 "없는 것"이 됐기 때문입니다 듀얼 모니터에서 절전이나 디스플레이 끄기 후 복귀하면 열어 둔 창이 전부 한쪽 화면으로 몰리거나 왼쪽 위에 쌓이는 증상이 있습니다. 고장이 아니라 모니터가 꺼지는 순간 윈도우에게 사라진 것으로 보이기 때문입니다. 구조와 완화책 사다리를 정리했습니다.
  • 모니터 절전에서 깨면 소리가 안 날 때 — 점호에 늦은 장치를 다시 깨우면 됩니다 절전 복귀 후 스피커가 침묵하는데 재부팅하면 돌아오는 증상은 오디오 경로의 어느 장치가 깨어나는 점호에 늦은 상태입니다. 재부팅 없이 그 장치만 다시 깨우는 방법과, 소리가 나오는 경로별 예방 스위치를 정리했습니다.
