마우스 드래그가 안 풀릴 때 — 버튼을 뗐는데 계속 끌려온다면 넷 중 하나입니다

2026년 11월 10일 · 2026년 11월 10일 갱신

창을 옮기려고 잡았다 놓았는데 창이 커서를 계속 따라옵니다. 파일을 끌었다 놓으면 그대로 붙어 다니고, 엉뚱한 곳에 떨어질까 봐 마우스를 움직이기도 겁납니다. 컴퓨터는 버튼이 아직 눌려 있다고 알고 있는 상태입니다.

지금 당장 — 한 번 더 누르거나 Esc

같은 버튼을 한 번 더 눌렀다 떼면 컴퓨터가 "뗌"을 다시 받아 대부분 풀립니다. 파일을 끌고 있는 중이라면 Esc를 누르면 끌기가 취소되고 원래 자리에 남습니다. 엉뚱한 폴더에 떨어뜨렸다면 바로 Ctrl + Z로 되돌릴 수 있습니다.

갈래 ① — 윈도우 클릭 잠금

버튼을 조금 길게 눌렀다 뗀 뒤부터 붙어 다니고, 다시 클릭하면 놓아진다면 윈도우의 클릭 잠금 기능입니다. 버튼을 계속 누르고 있기 힘든 사람을 위해 "잠깐 누르면 누른 상태로 잡아 두는" 기능이라, 켜져 있으면 일부러 그렇게 동작합니다.

  • 제어판의 마우스 설정(마우스 속성) → 단추 탭 → 클릭 잠금 켜기 체크를 해제합니다
  • 일부러 쓰는 사람이라면 같은 자리의 설정에서 잡히기까지 걸리는 시간을 늘릴 수 있습니다

이 갈래는 증상이 규칙적입니다 — 길게 누를 때마다 똑같이 일어납니다.

갈래 ② — 버튼 접점

오래 쓴 마우스에서 가끔, 불규칙하게 일어난다면 버튼 아래 스위치가 "뗌"을 제때 보고하지 못하는 경우입니다. 한 번 눌렀는데 두 번 눌리는 더블클릭 증상과 같은 뿌리라, 두 증상이 같이 있다면 거의 확실합니다 — 판별과 수리 저울은 한 번 눌렀는데 더블클릭이 될 때에 있습니다.

다른 마우스를 꽂아서 같은 동작이 멀쩡하면 원래 마우스 쪽으로 확정입니다.

갈래 ③ — 무선에서 빠진 신호

무선이나 블루투스 마우스는 버튼을 떼는 순간 연결이 잠깐 끊기면 "뗌" 신호가 빠져서 눌린 상태가 남는 사례가 있습니다. 키보드에서 Alt·Ctrl이 눌린 채로 남는 것과 같은 구조입니다 — 키가 눌린 채로 잡혔을 때.

  • 커서가 가끔 멈칫하거나 건너뛰는 증상도 있다면 이 갈래 쪽입니다 — 배터리·수신기 위치·간섭 순서는 무선 마우스 끊김 판정에 있습니다
  • 블루투스라면 페어링을 지우고 다시 연결하는 것이 리셋입니다

갈래 ④ — 특정 프로그램 안에서만

바탕화면·탐색기에서는 멀쩡한데 어떤 프로그램 안에서만 끌기가 안 풀린다면 그 프로그램의 문제입니다. 프로그램을 업데이트하거나 껐다 켜는 것이 먼저이고, 원격 접속 창 안에서만 그렇다면 원격 쪽 연결이 신호를 놓치는 경우입니다.

자주 묻는 질문

반대로 드래그하다가 중간에 놓쳐요

그건 버튼을 누르고 있는데 접점이 순간적으로 끊기는 쪽이라 갈래 ②와 같은 뿌리입니다 — 더블클릭이 될 때의 "드래그로 관찰" 판별이 그대로입니다.

노트북 터치패드에서도 그래요

터치패드는 "두 번 톡 친 뒤 끌기" 같은 동작이 켜져 있으면 손을 떼도 끌기가 이어지는 경우가 있습니다. 설정의 터치패드 항목에서 끌기 관련 동작을 확인해 보세요.

정리

  1. 지금 당장은 같은 버튼 한 번 더 클릭, 파일이면 Esc
  2. 길게 누를 때마다 규칙적으로 → 윈도우 클릭 잠금 끄기
  3. 오래 쓴 마우스에서 가끔 → 버튼 접점, 다른 마우스로 비교
  4. 무선·블루투스 → 뗌 신호 누락, 배터리·수신기·재연결
  5. 특정 프로그램에서만 → 그 프로그램 쪽

마우스의 이웃 판정들 — 더블클릭이 될 때 · 무선 마우스 끊김 · 키가 눌린 채로 잡혔을 때와 이어집니다.

기준이나 동작이 실제와 다르면 알려주세요. 확인 후 갱신합니다.

같이 보면 좋은 글

  • 네트워크 마우스 커서에 꼬리가 생길 때 — 설정 하나, 모니터 하나, 프로그램 하나 마우스를 움직이면 커서 뒤로 잔상이 줄줄이 따라옵니다. 윈도우의 포인터 자국 기능이 켜졌거나, 모니터의 응답속도 보정이 과하거나, 특정 프로그램의 그리기 문제인 경우가 대부분입니다. 어디서 꼬리가 보이는지로 가르는 순서를 정리했습니다.
  • 네트워크 마우스 휠 스크롤이 너무 빠를 때 — 줄 수 설정, 휠 모드, 프로그램 순서로 봅니다 휠을 한 칸만 굴렸는데 화면이 한참 내려가거나, 한 번 굴리면 멈추지 않고 계속 돕니다. 윈도우의 스크롤 줄 수, 마우스의 휠 모드(프리 스핀), 프로그램의 부드러운 스크롤 중 하나인 경우가 대부분입니다. 가르는 순서와, 휠이 튀는 고장과의 구분을 정리했습니다.
  • 네트워크 마우스 커서가 사라졌을 때 — "안 보이는" 건지 "안 움직이는" 건지부터 화면에서 마우스 커서가 안 보입니다. 다른 화면으로 넘어갔을 뿐인 경우, 특정 프로그램에서만 숨는 경우, 마우스 입력 자체가 끊긴 경우, 노트북 터치패드가 꺼진 경우는 처방이 전부 다릅니다. 커서 없이 움직이는 법과 갈래 가르는 순서를 정리했습니다.
