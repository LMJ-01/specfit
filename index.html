골라 읽기 좋은 글

  • GPU Ollama 최소 사양 — 내 VRAM으로 몇 B 모델까지 돌아가나 로컬 LLM을 돌리기 전에 확인할 것은 GPU 이름이 아니라 VRAM입니다. VRAM 용량별로 실제 돌아가는 모델 크기를 정리했습니다.
  • 노트북 개발용 노트북 사양 — 나중에 못 바꾸는 것부터 고르세요 노트북은 부품 대부분을 나중에 못 바꿉니다. 램, 화면, 그래픽카드 순으로 살 때 정해야 할 것과 나중에 해도 되는 것을 갈랐습니다.
  • 모니터 코딩용 모니터 — 27과 32, QHD와 4K 조합 고르기 코딩에서 갈리는 건 주사율이나 색재현율이 아니라 해상도와 크기의 조합입니다. 27 QHD·32 QHD·27 4K·32 4K를 PPI로 계산해 어느 조합이 맞는지 정리했습니다.
  • 메모리·스토리지 램 16GB vs 32GB — 로컬 LLM과 개발에서 갈리는 지점 32GB를 사라는 답은 쓸모가 적습니다. 로컬 LLM에서 필요한 램은 GPU가 정합니다. VRAM을 넘긴 만큼이 시스템 램으로 넘어오기 때문입니다. 계산해서 정리했습니다.
  • 미니PC 미니PC vs 노트북 — 갈림길은 성능이 아니라 이동입니다 어차피 책상에서만 쓰는데 노트북이 맞을까요. 속이 같은 두 물건이라 성능으로는 안 갈립니다. 밖에서 화면을 열 일이 있는지, 이미 갖고 있는 물건이 무엇인지로 갈립니다.
  • 네트워크 메시 와이파이 — 성능은 위성이 아니라 백홀이 정합니다 방마다 안 터져서 메시를 알아보면 위성 개수부터 세게 됩니다. 순서가 반대입니다. 위성들이 서로 어떻게 연결되는가(백홀)가 성능을 정하고, 집에 벽 랜포트가 있느냐로 답이 갈립니다.

  • GPU 그래픽카드 인식이 안 될 때 — "어디까지 보이는지"가 갈래를 알려줍니다 9.6
  • 노트북 키보드 특정 키만 안 눌릴 때 — 어느 키들이 같이 죽었는지가 단서입니다 9.6
  • 노트북 배터리로 쓰면 노트북이 느려질 때 — 성능은 전력 예산의 함수입니다 9.6
  • 모니터 절전에서 깨면 창이 한쪽 모니터로 몰릴 때 — 모니터가 잠깐 "없는 것"이 됐기 때문입니다 9.6
  • GPU 컴퓨터에서 타는 냄새가 날 때 — 진단보다 전원 차단이 먼저입니다 9.6
  • 메모리·스토리지 오래 켜두면 느려지고 재부팅하면 빨라질 때 — "낫는다"는 것 자체가 단서입니다 9.6
  • 네트워크 인터넷은 되는데 특정 사이트만 안 열릴 때 — 두 번의 맞바꾸기로 층이 갈립니다 9.6
  • 모니터 게임 중 마우스가 옆 모니터로 나갈 때 — 반대 고민 둘이 같은 구조입니다 9.5
