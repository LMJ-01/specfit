스펙핏 — 내 조건에 맞는 스펙

AI·개발 작업용 하드웨어를 스펙 기준으로 골라드립니다. GPU, 노트북, 모니터를 용도와 예산에 맞춰 비교합니다.

  • GPU RTX 4060 Ti 16GB vs RTX 4070 — VRAM이냐 속도냐 신품 중급 구간에서 가장 많이 갈리는 선택입니다. 4060 Ti는 VRAM 16GB, 4070은 대역폭 1.75배. 어느 쪽이 맞는지 모델 크기별로 갈랐습니다.
  • GPU RTX 4060으로 로컬 LLM — 8GB로 어디까지 되나 가장 흔한 입문 카드인 RTX 4060의 VRAM은 8GB입니다. 어떤 크기 모델이 쾌적하게 돌고 어디서 막히는지, 8GB의 한계선을 정리했습니다.
  • GPU 중고 RTX 3060 12GB — 로컬 LLM 입문에 아직 쓸 만한가 단종된 구형 카드지만 VRAM 12GB로 14B 모델이 여유롭게 돌아갑니다. 신품 4060 8GB와 비교해 어느 쪽이 맞는지, 중고로 살 때 확인할 것을 정리했습니다.
  • GPU 중고 RTX 3090 vs 신품 4070 — 로컬 LLM은 어느 쪽 로컬 LLM에서는 세대가 낮아도 VRAM이 큰 쪽이 유리합니다. 3090 24GB와 4070 12GB를 실제 기준으로 비교했습니다.
  • 메모리·스토리지 로컬 LLM 램 몇 GB 필요한가 — VRAM과 뭐가 다른가 로컬 LLM에서 시스템 램과 VRAM은 역할이 다릅니다. 어느 쪽이 부족할 때 무슨 일이 생기는지, 얼마나 필요한지 정리했습니다.
  • GPU Ollama 최소 사양 — 내 VRAM으로 몇 B 모델까지 돌아가나 로컬 LLM을 돌리기 전에 확인할 것은 GPU 이름이 아니라 VRAM입니다. VRAM 용량별로 실제 돌아가는 모델 크기를 정리했습니다.
