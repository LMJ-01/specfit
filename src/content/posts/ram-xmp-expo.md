이 사이트는 램 이야기를 할 때마다 **"우선순위는 용량 → 듀얼 채널 → 클럭"** 이라고 적었습니다.
클럭은 마지막이니 신경 쓰지 말라는 뜻이었습니다.

**그런데 그 마지막 항목조차 기본 설정으로는 안 나옵니다.**

`DDR5-6000` 이라고 적힌 램을 사서 꽂아도, 아무것도 안 하면 **4800 으로 돕니다.**
고장이 아니라 설계대로입니다.

## 결론부터

| | |
|---|---|
| 왜 안 나오나 | 표기 속도는 **규격 밖**이라 기본으로 안 켜집니다 |
| 기본값은 얼마 | DDR5 **4800** · DDR4 **2133** (대개) |
| 켜면 얼마나 오르나 | **DDR5 +17~25% · DDR4 +50%** — 아래 계산 |
| 어디서 체감되나 | **CPU 로 넘어가는 작업** 하나입니다 |
| 어디서는 상관없나 | 모델이 VRAM 에 다 올라가면 **차이 없음** |
| 노트북은 | **대개 설정 자체가 없습니다.** 해당 없음 |

**켜는 건 5분이고 돈이 안 듭니다.** 다만 켜서 얻는 게 있는 사람과 없는 사람이 갈립니다.

## 1. 왜 산 속도가 안 나오나

램에는 **두 벌의 속도 표가** 들어 있습니다.

| | 무엇 | 기본 동작 |
|---|---|---|
| **JEDEC** | 업계 표준 규격 | ✅ **이걸로 돕니다** |
| **XMP · EXPO** | 제조사가 따로 넣어둔 프로필 | ❌ 켜야 동작합니다 |

상자에 적힌 `6000` 은 두 번째입니다. **표준을 넘는 값이라 기본으로 켜면 안 되는 것**입니다 —
메인보드와 CPU 조합에 따라 그 속도가 안 나올 수도 있으니까요.

그래서 제조사는 프로필만 넣어두고, **켜는 것은 사용자에게 맡깁니다.**

```
상자에 적힌 값   DDR5-6000   ← XMP·EXPO 프로필
아무것도 안 하면  DDR5-4800   ← JEDEC 표준
```

**이름만 다릅니다.** 인텔 쪽이 `XMP`, AMD 쪽이 `EXPO` 이고 하는 일은 같습니다.
메인보드에 따라 `D.O.C.P` 처럼 또 다른 이름으로 적혀 있기도 합니다.

## 2. 얼마나 손해인가 — 계산됩니다

이 사이트가 계속 쓰는 식 그대로입니다.

```
대역폭 = 클럭 × 8바이트 × 장수
```

두 장(듀얼 채널) 기준으로 넣어 보면 이렇습니다.

| 산 것 | 안 켰을 때 | 켰을 때 | 차이 |
|------|----------|--------|------|
| DDR5-5600 | 76.8 GB/s | 89.6 GB/s | **+17%** |
| **DDR5-6000** | **76.8 GB/s** | **96.0 GB/s** | **+25%** |
| **DDR4-3200** | **34.1 GB/s** | **51.2 GB/s** | **+50%** |

**DDR4 쪽이 손해가 더 큽니다.** 기본값(2133)과 표기값(3200)의 간격이 넓기 때문입니다.

바꿔 말하면 이렇습니다.

```
DDR5-6000 을 사놓고 안 켜면  →  4800 짜리를 산 것과 같습니다
DDR4-3200 을 사놓고 안 켜면  →  2133 짜리를 산 것과 같습니다
```

**웃돈을 내고 산 부분이 통째로 안 쓰이는 상태**입니다.

## 3. ⚠️ 그런데 대부분의 작업에서는 체감이 없습니다

여기가 이 글에서 가장 중요한 부분입니다. **켜라고만 하는 글이 안 적는 것**이기도 합니다.

램 대역폭이 병목인 작업이 별로 없습니다.

| 작업 | 체감 |
|------|------|
| 빌드·컴파일 | 거의 없음 — 병목이 **CPU 코어 수** |
| 에디터·브라우저 | 없음 |
| 도커 컨테이너 | 없음 — 병목이 **용량** |
| `npm install` | 없음 — 병목이 디스크의 작은 파일 처리 |
| **내장 그래픽으로 화면 출력** | **큽니다** — 전용 메모리가 없어 시스템 램을 씁니다 |
| **CPU 로 AI 모델 돌리기** | **큽니다** — 대역폭이 곧 속도입니다 |

**아래 두 줄만 갈립니다.** 그리고 둘 다 이유가 같습니다 — **메모리를 쉬지 않고 읽는 작업**입니다.

[램 16GB vs 32GB](/posts/ram-16gb-vs-32gb.html) 에서 *"부족하면 문제가 되는 건 용량이지 속도가 아니다"* 라고
적은 것이 여기서도 그대로 성립합니다. **XMP 는 속도를 올리는 것이지 용량을 늘리는 게 아닙니다.**

## 4. 로컬 LLM 에서는 — 한 경우만 의미 있습니다

**모델이 VRAM 에 다 올라가면 시스템 램은 거의 놀고 있습니다.**
이때는 XMP 를 켜든 말든 생성 속도가 같습니다.

의미가 생기는 건 **VRAM 을 넘겨서 CPU 가 일을 떠맡을 때**입니다.

```
전부 VRAM 에 올라감    →  XMP 켜도 그대로
CPU 로 일부 넘어감     →  넘어간 몫이 그만큼 빨라짐
GPU 없이 CPU 로만      →  대역폭이 곧 속도. 여기가 가장 큽니다
```

**내 조합이 어느 쪽인지부터 확인하세요.**

{{VRAM_TOOL}}

**"여유" 로 나오면 XMP 를 켜도 생성 속도는 안 바뀝니다.**
"느림" 이나 "불가" 로 나온다면 그때부터 이 글이 의미가 있습니다.

> ⚠️ **[CPU 로 돌릴 때의 계산](/posts/local-llm-without-gpu.html)에 쓴 `DDR5-5600 = 89.6GB/s` 는
> XMP 를 켠 값입니다.** 안 켜면 76.8GB/s 이고, 그 글의 표에서 한 칸 아래로 내려갑니다.
> 그래도 결론은 안 바뀝니다 — 가장 저렴한 신품 그래픽카드와도 여전히 몇 배 차이입니다.

## 5. ⚠️ 노트북은 대개 해당이 없습니다

**노트북에는 이 설정이 거의 없습니다.**

제조사가 BIOS 에서 메모리 항목을 아예 막아두는 경우가 대부분이고,
노트북용 `SO-DIMM` 은 애초에 JEDEC 표준 속도로 파는 물건입니다.

| | 데스크톱 | 노트북 |
|---|---|---|
| 설정 항목 | 대개 있습니다 | **대개 없습니다** |
| 파는 속도 | 표기 속도 = 프로필 | **표준 속도 그대로** |
| 할 수 있는 것 | 켜기 | **장수를 맞추기** |

그래서 노트북에서 대역폭을 올리는 방법은 하나뿐입니다 — **두 장으로 꽂는 것.**
[노트북 램 교체](/posts/laptop-ram-upgrade.html)에서 *"32GB 한 장은 16GB 두 장보다 대역폭이 절반"*
이라고 적은 그 항목이고, **노트북에서는 그게 XMP 자리를 대신합니다.**

## 6. 새로 살 거라면 — 속도 등급에 웃돈을 내지 마세요

**순서가 바뀌지 않습니다.**

```
용량  →  장수(듀얼 채널)  →  규격  →  속도 등급
```

속도 등급은 여전히 마지막입니다. 이 글은 **"클럭을 먼저 보라"** 는 글이 아니라
**"이미 산 것을 안 쓰고 있을 수 있다"** 는 글입니다.

같은 이유로 클럭보다 먼저 볼 것이 장수입니다 — 두 장을 꽂고도 싱글로
돌고 있을 수 있습니다. [듀얼 채널 확인법](/posts/ram-dual-channel-check.html)에서
1분이면 확인됩니다.

| 같은 값이면 | 어느 쪽 |
|-----------|--------|
| DDR5-6000 **한 장** vs DDR5-4800 **두 장** | **두 장** — 76.8 vs 96.0 이 아니라 48.0 vs 76.8 입니다 |
| 고클럭 32GB vs 표준 클럭 **64GB** | 용량이 부족하다면 **용량** |
| 고클럭 램 vs **같은 값의 SSD·모니터** | 대개 그쪽 |

**한 장짜리 고클럭은 가장 나쁜 조합입니다.** 켜도 두 장의 표준 클럭을 못 이깁니다.

> 예전보다 부담입니다 — [램 값이 올랐습니다](/posts/ram-price-2026.html)에 판단 기준이 있습니다.

## 7. 지금 내 램이 몇으로 돌고 있는지

**켜기 전에 확인부터 하세요.** 이미 켜져 있는 경우가 있습니다.

`Ctrl` + `Shift` + `Esc` → **성능** → **메모리**. 오른쪽에 나옵니다.

```
속도    4800 MT/s    ← 상자에 6000 이라고 적혀 있었다면 안 켜진 것
속도    6000 MT/s    ← 이미 켜져 있습니다. 할 일 없습니다
```

**상자·주문 내역의 숫자와 이 숫자를 비교하는 게 전부입니다.**
같으면 아무것도 안 하셔도 됩니다.

### 켜는 법

메인보드 제조사마다 메뉴 이름이 다릅니다. **찾을 단어는 셋 중 하나입니다.**

1. 재부팅하면서 `Del` 또는 `F2` 를 눌러 BIOS 진입
2. 메모리·오버클럭 메뉴에서 **`XMP`** · **`EXPO`** · **`D.O.C.P`** 를 찾습니다
3. `Disabled` → **`Profile 1`** 로
4. 저장하고 재부팅 (대개 `F10`)
5. 작업 관리자에서 속도가 바뀌었는지 확인

**프로필이 여러 개면 1번이 무난합니다.** 2번은 더 높은 값인 경우가 많고,
그만큼 안 잡힐 확률도 올라갑니다.

> ⚠️ **규격상 이건 오버클럭입니다.** 제조사가 검증한 프로필이라 대개 안정적이지만
> **보장된 동작은 아닙니다.** 메인보드·CPU 조합에 따라 안 잡힐 수 있습니다.
>
> 부팅이 안 되면 **당황하지 마세요.** 몇 번 실패하면 메인보드가 스스로 기본값으로
> 되돌립니다. 안 되면 BIOS 초기화(케이스를 열어 점퍼나 배터리)로 돌아옵니다.
> **되돌릴 수 있는 설정**이라 SSD·램 교체보다 위험이 작습니다.

## 자주 묻는 질문

### 안 켜면 램이 고장 난 건가요

아닙니다. **표준 속도로 정상 동작하고 있는 것**입니다.
상자에 적힌 값은 표준을 넘는 프로필이라 기본으로 켜지지 않습니다.
DDR5 는 대개 4800, DDR4 는 2133 으로 잡힙니다.

### 켜면 얼마나 빨라지나요

**대역폭 기준으로 DDR5 는 17~25%, DDR4 는 50% 정도 올라갑니다.**
다만 그게 체감으로 오는 작업은 제한적입니다.
빌드·에디터·도커에서는 거의 안 느껴지고, **CPU 로 AI 모델을 돌리거나
내장 그래픽을 쓸 때만** 그대로 반영됩니다.

### 위험한가요

규격상 오버클럭이지만 **제조사가 검증해 넣어둔 프로필**이라 대개 안정적입니다.
다만 메인보드·CPU 조합에 따라 안 잡힐 수 있고, 그때는 부팅이 몇 번 실패한 뒤
기본값으로 되돌아옵니다. **되돌릴 수 있는 설정**입니다.

### 노트북에서도 켤 수 있나요

**대개 없습니다.** 제조사가 BIOS 메모리 항목을 막아두는 경우가 대부분이고,
노트북용 SO-DIMM 은 표준 속도로 파는 물건입니다.
노트북에서 대역폭을 올리려면 **두 장으로 꽂는 것**이 유일한 방법입니다 —
[노트북 램 교체](/posts/laptop-ram-upgrade.html)에 있습니다.

### 로컬 LLM 이 빨라지나요

**모델이 VRAM 에 다 올라간다면 아닙니다.** 그때는 시스템 램이 거의 안 쓰입니다.
VRAM 을 넘겨 CPU 로 넘어가는 상황이거나 [GPU 없이 돌리는 경우](/posts/local-llm-without-gpu.html)에만
의미가 있습니다. 위 계산기에서 "여유" 로 나오면 켜도 그대로입니다.

### 램을 더 사는 것과 XMP 중 뭐가 먼저인가요

**용량이 부족하다면 용량이 먼저입니다.** XMP 는 속도를 올리는 것이지 용량을 늘리지 않습니다.
부족한지 확인하는 법은 [램 16GB vs 32GB](/posts/ram-16gb-vs-32gb.html)에 있습니다.
용량이 충분한데 한 장으로 꽂혀 있다면, **XMP 보다 한 장 더 꽂는 쪽이 큽니다.**

### 두 장의 속도가 다르면요

**낮은 쪽으로 맞춰집니다.** 프로필도 낮은 쪽 기준으로 잡히거나 아예 안 잡힐 수 있습니다.
가능하면 같은 제품 두 장이 안전합니다 —
[DDR4와 DDR5](/posts/ddr4-vs-ddr5.html)에 규격 이야기를 정리했습니다.

## 정리

1. 상자에 적힌 속도는 **프로필**입니다. 켜야 나옵니다
2. 기본값은 **DDR5 4800 · DDR4 2133** 입니다. 안 켜면 그 속도로 돕니다
3. 켜면 대역폭이 **DDR5 17~25% · DDR4 50%** 오릅니다. DDR4 쪽이 더 큽니다
4. **대부분의 개발 작업에서는 체감이 없습니다.** 빌드는 CPU, 도커는 용량이 병목입니다
5. 갈리는 건 둘뿐 — **CPU 추론**과 **내장 그래픽**입니다
6. **노트북은 대개 해당이 없습니다.** 거기서는 장수를 맞추는 게 답입니다
7. 순서는 그대로입니다 — **용량 → 장수 → 규격 → 속도 등급**

지금 몇으로 돌고 있는지는 작업 관리자 → 성능 → 메모리에서 5초면 확인됩니다.
