노트북을 사고 나서 아쉬운 게 생겼을 때, **바꿀 수 있는 건 사실상 SSD 하나**입니다.

램은 [대개 납땜되어 못 늘리고](/posts/laptop-ram-onboard-lpcamm2.html), 화면과 그래픽카드는 아예 못 바꿉니다. 그런데 SSD는 다릅니다.

**그래서 [노트북을 살 때 SSD에서 아끼라](/posts/dev-laptop-spec.html)고 적었던 것**입니다. 나중에 해결되는 쪽이니까요. 이 글은 그 "나중에"에 해당합니다.

## 결론부터

| 단계 | 확인할 것 |
|------|---------|
| 1 | **슬롯이 몇 개인가** — 2개면 추가, 1개면 교체 |
| 2 | **길이 규격** — 2280이 흔하지만 2242·2230도 있습니다 |
| 3 | **NVMe를 받는가** — 오래된 모델은 SATA만 받기도 합니다 |
| 4 | 보증이 깨지는가 — 제조사마다 다릅니다 |

| 상황 | 방법 |
|------|------|
| 슬롯이 **2개** | 하나 더 꽂기 — **가장 쉽습니다** |
| 슬롯이 **1개** | 통째로 교체 + 복제 또는 재설치 |
| **납땜** | 불가능합니다 |

## 1. 먼저 — 내 노트북이 바꿀 수 있는 물건인가

**대부분 됩니다.** 다만 확인은 하셔야 합니다.

### 확인하는 법

**① 제품 사양에서**

- "M.2 슬롯 2개" 처럼 개수가 적혀 있으면 확실합니다
- "확장 슬롯", "저장장치 확장" 같은 표현도 같은 뜻입니다
- **아무 언급이 없으면** 다음 방법으로 넘어가세요

**② 분해 후기 검색**

가장 확실합니다. 모델명으로 검색하면 뒷판을 연 사진이 대개 나옵니다.
**빈 슬롯이 보이면 추가할 수 있습니다.**

**③ 이미 쓰고 계신 노트북이라면**

`Ctrl` + `Shift` + `Esc` → **성능** → **디스크**.
디스크가 하나만 보인다고 슬롯이 하나인 건 아니지만, 두 개 보이면 확실히 두 개입니다.

### ⚠️ 안 되는 경우

**초슬림 모델 중에는 SSD도 메인보드에 붙어 있는 것**이 있습니다. 이 경우 방법이 없습니다.

램과 SSD가 둘 다 납땜이면 그 노트북은 **산 상태가 끝**입니다. 다음에 사실 때는 이걸 먼저 보세요.

## 2. 규격 — 길이가 다르면 안 들어갑니다

**M.2 SSD는 길이가 여러 가지입니다.** 숫자 네 자리가 크기입니다.

| 표기 | 크기 | 어디에 |
|------|------|-------|
| **2280** | 22 × 80mm | 가장 흔합니다 |
| 2242 | 22 × 42mm | 얇은 노트북 |
| 2230 | 22 × 30mm | 초소형·휴대기기 |

**2280을 샀는데 자리가 2242면 안 들어갑니다.** 반대로 짧은 걸 긴 자리에 넣는 건 나사 위치만 맞으면 되는 경우가 있습니다.

**분해 사진에서 기존 SSD의 길이를 보고 맞추는 게 가장 확실합니다.**

### 방식도 확인하세요

M.2 슬롯이라고 NVMe를 다 받는 게 아닙니다. 오래된 모델은 SATA만 받기도 합니다.
차이는 [NVMe와 SATA](/posts/nvme-vs-sata.html)에 정리했습니다.

**대략 이렇게 보시면 됩니다.**

- 최근 몇 년 안에 나온 노트북 → 거의 NVMe
- 그보다 오래됐으면 → 확인 필요

## 3. 슬롯이 2개면 — 제일 쉽습니다

**기존 것을 그대로 두고 하나 더 꽂으면 끝입니다.**

- 운영체제를 다시 깔 필요 없습니다
- 복제할 필요도 없습니다
- 꽂고 켜면 새 드라이브로 잡힙니다

**윈도우에서 안 보이면** — 새 SSD는 초기화가 안 된 상태라 탐색기에 안 나옵니다.
`디스크 관리`를 열면 "초기화되지 않음"으로 보이고, 거기서 초기화하고 볼륨을 만들면 나타납니다.

### 개발자에게 유용한 배치

두 개를 이렇게 나눠 쓰면 편합니다.

```
1번 (기존)   운영체제, 프로그램
2번 (추가)   프로젝트 소스, 도커 이미지, 로컬 LLM 모델
```

특히 **도커 이미지와 모델 파일이 용량을 크게 먹습니다.** 이걸 두 번째로 몰아두면 시스템 드라이브가 여유로워집니다.

## 4. 슬롯이 1개면 — 두 가지 방법

### 방법 A. 복제 (권장)

기존 내용을 그대로 옮기는 방법입니다. **프로그램을 다시 깔 필요가 없습니다.**

```
1. 외장 케이스(M.2 → USB)에 새 SSD를 넣습니다
2. 복제 프로그램으로 기존 → 새 SSD 복사
3. 노트북을 열어 SSD를 바꿔 끼웁니다
4. 부팅 확인
```

**외장 케이스가 따로 필요합니다.** 다 쓰고 나면 기존 SSD를 넣어 외장 디스크로 쓸 수 있어서 버려지지는 않습니다.

> ⚠️ **복제 전에 중요한 파일은 따로 백업하세요.**
> 복제는 대개 잘 되지만, 실패했을 때 원본까지 건드리는 경우가 드물게 있습니다.

### 방법 B. 새로 설치

윈도우를 새로 까는 방법입니다. **깨끗해지는 대신 프로그램을 다시 깔아야 합니다.**

개발 환경은 다시 세팅하는 데 시간이 꽤 걸립니다. **복제 쪽이 대개 낫습니다.**

## 5. 열기 전에 알아둘 것

**① 보증**

제조사와 모델마다 다릅니다. **저장장치 교체를 허용하는 곳도 있고, 봉인 스티커가 붙어 있는 곳도 있습니다.**
보증 기간이 남아 있다면 제조사에 먼저 확인하시는 게 안전합니다.

**② 전원**

전원을 끄고 어댑터를 뽑습니다. **내장 배터리 커넥터를 분리하라고 안내하는 모델도 있습니다.**

**③ 정전기**

금속 부분을 한 번 만져 정전기를 빼고 시작합니다.

**④ 나사**

뒷판 나사가 길이가 다른 경우가 많습니다. **뺀 자리를 기억해두세요.** 긴 나사를 짧은 자리에 박으면 기판이 상합니다.

**⑤ 발열**

노트북은 공간이 좁아 SSD 열이 잘 안 빠집니다. **Gen5는 노트북에 권하지 않습니다** — 방열판 자리가 없어 스스로 속도를 낮춥니다. Gen4면 충분합니다.

## 6. 용량 — 얼마짜리를 사나

| 용도 | 권장 |
|------|-----|
| 일반 개발만 | 512GB |
| 개발 + 도커 | **1TB** |
| **로컬 LLM 겸용** | **1TB 이상, 2TB면 여유** |

로컬 LLM을 하시면 계산이 달라집니다. **모델 하나가 5~43GB**입니다.

| 모델 | Q4 파일 |
|------|--------|
| 7~8B | 약 4.7GB |
| 14B | 약 9GB |
| 32B | 약 20GB |
| 70B | 약 43GB |

이것저것 받다 보면 금방 수십 GB가 됩니다. `ollama list`로 확인하고 안 쓰는 건 지우세요.

도커도 조용히 쌓입니다 — [도커 노트북 사양](/posts/docker-laptop-spec.html)에 정리 명령을 적어뒀습니다.

> **SSD는 80% 넘게 채우지 마세요.** 빈 공간이 부족하면 내부 정리가 어려워져
> 속도가 떨어지고 수명에도 불리합니다.

## 자주 묻는 질문

### 램도 같이 늘릴 수 있나요

**대개 못 늘립니다.** 최근 얇은 노트북은 램이 납땜되어 있습니다.
뒷판을 열었을 때 램 슬롯이 보이면 가능합니다 —
[노트북 램 나중에 못 늘립니다](/posts/laptop-ram-onboard-lpcamm2.html)에 확인법이 있습니다.

### 기존 SSD는 어떻게 하나요

외장 케이스에 넣으면 **외장 SSD로 쓸 수 있습니다.** 백업용으로 유용합니다.
로컬 LLM 모델 중 자주 안 쓰는 것을 여기 옮겨두는 것도 방법입니다.

### 복제하면 윈도우 정품 인증이 풀리나요

같은 노트북 안에서 저장장치만 바꾸는 것이라 대개 유지됩니다.
다만 안 되는 경우가 있으니 **마이크로소프트 계정에 연결해두면** 복구가 쉽습니다.

### SSD를 바꾸면 개발이 얼마나 빨라지나요

**하드디스크에서 바꾸는 거라면 크게 빨라집니다.**
이미 SSD를 쓰고 계셨다면 체감은 작습니다 — 개발 작업의 병목이 순차 속도가 아니기 때문입니다.
자세한 이유는 [NVMe와 SATA](/posts/nvme-vs-sata.html)에 있습니다.

**용량이 부족해서 바꾸는 거라면 그건 확실한 이유입니다.**

### 로컬 LLM 속도가 빨라지나요

아닙니다. 모델을 처음 읽어 올릴 때만 쓰이고, 이후 연산은 VRAM 안에서 일어납니다.
**용량 문제를 푸는 것이지 속도 문제를 푸는 게 아닙니다.**

### 뒷판이 안 열립니다

나사를 다 뺐는데 안 열리면 **숨은 나사가 고무 발 아래**에 있는 경우가 많습니다.
무리하게 벌리면 걸쇠가 부러집니다. 분해 영상을 한 번 보고 하시는 게 안전합니다.

## 정리

1. 노트북에서 **바꿀 수 있는 건 사실상 SSD 하나**입니다
2. **슬롯 개수부터 확인하세요.** 2개면 그냥 하나 더 꽂으면 됩니다
3. **길이 규격(2280/2242/2230)이 다르면 안 들어갑니다**
4. 슬롯이 1개면 **복제**가 낫습니다. 개발 환경 다시 까는 게 더 오래 걸립니다
5. **노트북에 Gen5는 권하지 않습니다.** 열이 안 빠집니다
6. 로컬 LLM을 겸하면 **1TB 이상**입니다. 모델 하나가 최대 43GB입니다
