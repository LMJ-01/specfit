한국어로 또박또박 물었는데 **답은 영어로** 옵니다. 다시 한국어로 물어도
영어, 혹은 처음 몇 번은 한국어로 잘 답하다가 **대화가 길어지자 어느 순간
영어로** 바뀝니다. 설치는 잘 됐고 답의 내용도 멀쩡해서 더 헷갈리는
증상입니다.

고장이 아니라 **모델이 원래 영어 쪽으로 기울어 있고, 그걸 붙잡아 두던
지시가 약하거나 사라진 상태**입니다. 그리고 원인은 대개 셋 중 하나라서,
**언제 영어로 바뀌는지**만 보면 갈래가 잡힙니다.

## 언제 바뀌는지로 가릅니다

| 언제 영어로 답하나 | 유력한 원인 | 먼저 할 것 |
|------|------|------|
| **처음부터** 거의 매번 | 영어 위주로 배운 모델 | 한국어에 강한 계열로 바꾸기 |
| 짧은 질문엔 한국어, **코드·전문 용어가 섞이면** 영어 | 작은 모델이 지시를 못 버팀 | 지시를 시스템 프롬프트로 고정, 한 체급 위 |
| 잘 하다가 **대화가 길어진 뒤부터** | 처음 준 "한국어로" 지시가 잘려 나감 | 지시를 시스템 프롬프트로, 새 대화 |

## 원인 ① — 모델이 영어 쪽으로 기울어 있습니다

공개된 언어 모델은 대부분 **영어 글을 압도적으로 많이** 보고 자랐습니다.
그래서 한국어 질문을 알아듣기는 해도, 답을 만들 때는 익숙한 영어 쪽으로
미끄러지기 쉽습니다. 모델 계열마다 이 기울기가 크게 다르고 — 같은 크기라도
어떤 계열은 한국어로 자연스럽게 답하고, 어떤 계열은 한국어 문장을 몇 줄
쓰다 영어로 넘어갑니다.

처음부터 거의 매번 영어라면 이 갈래입니다. 설정보다 **모델을 바꾸는 쪽**이
빠릅니다. [설치 가이드](/posts/ollama-install-guide.html)에서 무난하다고 적은
`qwen2.5` 계열처럼 여러 언어를 고르게 배운 계열이나, 한국 기업이 한국어를
중심으로 학습해 공개한 계열이 후보입니다(라이선스와 크기 단계는 모델마다
다르니 `ollama.com/library`의 모델 페이지에서 확인하세요). 다국어 모델
중에는 영어 대신 **중국어가 섞여** 나온다는 보고가 있는 것도 있어, 그런
모습이 보이면 같은 갈래로 보면 됩니다.

## 원인 ② — 작은 모델은 지시를 끝까지 못 버팁니다

3B·7~8B 같은 작은 모델은 "한국어로 답해"라는 지시를 받아도, **질문에 영어
코드나 전문 용어가 많이 섞이면** 그쪽에 끌려가 영어로 답하는 일이 잦습니다.
지시를 지키는 힘 자체가 크기에 따라 달라서, 같은 계열이라도 한 체급 위
(예: 7~8B → 14B)가 언어를 더 잘 지키는 편입니다.

다만 체급을 올리는 건 VRAM이 허락할 때 이야기입니다 — 내 카드에 14B가
들어가는지는 [VRAM별 한계선 지도](/posts/ollama-minimum-spec.html)로 먼저
보세요. 안 들어가는 모델은 영어 문제보다 [속도 문제가 더 커집니다](/posts/vram-8gb-tips.html).
체급을 못 올린다면 아래 처방 ②(지시를 시스템 프롬프트로 고정)가 같은
크기에서 할 수 있는 최선입니다.

## 원인 ③ — 처음 준 "한국어로" 지시가 잘려 나갔습니다

대화를 시작할 때 "앞으로 한국어로 답해 줘"라고 한 번 말해 두고 잘 쓰다가,
**길어진 뒤부터 영어로** 바뀌었다면 이 갈래를 의심합니다.

Ollama는 모델이 한 번에 기억하는 분량(**컨텍스트 길이**)을 넘는 입력이
들어오면 **앞부분을 잘라내고 그냥 실행**합니다. 화면에는 아무 표시가
없습니다. 대화가 쌓이면 가장 오래된 메시지부터 밀려나는데 — 그 안에 처음
부탁한 "한국어로"가 들어 있었다면, 모델 입장에서는 **그런 부탁을 받은 적이
없는 상태**가 됩니다. 기본 컨텍스트가 생각보다 짧다는 것과 잘렸는지 확인하는
법은 [컨텍스트 길이 설정](/posts/ollama-context-length.html)에 정리돼 있습니다.

처방의 핵심은 지시를 **대화 메시지가 아니라 시스템 프롬프트**에 두는 것입니다.
시스템 프롬프트는 대화 맨 앞에 따로 붙는 지시라, 지금 버전의 Ollama는
앞부분을 잘라낼 때도 이것은 남기는 쪽으로 동작합니다(버전에 따라 다를 수
있습니다). 당장은 **새 대화로 시작**하는 것만으로도 돌아옵니다.

## 처방 — 가벼운 것부터

**① 질문 끝에 한 줄** — 가장 간단합니다. 질문 끝에 "한국어로 답해 주세요"를
붙이면, 지시가 질문 바로 옆에 있어 작은 모델도 잘 지킵니다. 매번 붙이기
번거롭다는 게 단점입니다.

**② 이번 대화 동안 고정** — `ollama run` 으로 대화 중이라면:

```
/set system 너는 항상 한국어로 답한다. 코드와 명령어는 그대로 두고 설명만 한국어로 한다.
```

이 대화 동안 시스템 프롬프트로 붙습니다. 마음에 들면 `/save 내모델이름` 으로
지금 설정을 새 모델 이름으로 저장해 두고, 다음부터는 그 이름으로 실행하면
됩니다.

**③ 아예 모델에 박아 두기** — Modelfile로 지시가 들어간 변형을 만듭니다:

```
FROM qwen2.5:7b
SYSTEM """너는 항상 한국어로 답한다. 코드와 명령어는 그대로 두고 설명만 한국어로 한다."""
```

```
ollama create qwen2.5-ko -f Modelfile
```

이후 `ollama run qwen2.5-ko` 로 쓰면 매번 지시할 필요가 없습니다. 같은
Modelfile에 컨텍스트 길이(`PARAMETER num_ctx`)를 함께 넣어 두면 원인 ③도
같이 줄어듭니다 — 늘리는 만큼 VRAM이 더 드는 건
[그 글의 계산표](/posts/ollama-context-length.html)를 보고 정하세요.

**④ 그래도 영어라면 모델을 바꿉니다** — 시스템 프롬프트까지 넣었는데도
처음부터 영어로 기운다면 원인 ①입니다. 지시로 이기기 어려운 기울기라,
계열을 바꾸거나 VRAM이 허락하면 한 체급 올리는 쪽이 정답입니다.

## 자주 묻는 질문

### 답은 한국어인데 "생각하는 과정"이 영어로 나와요

답하기 전에 생각 과정을 보여 주는 모델은 **그 부분이 영어(또는 다른
언어)로 나오는 일이 흔합니다.** 모델이 익숙한 언어로 정리한 뒤 답을
쓰는 것이라 고장이 아니고, 최종 답이 한국어면 그대로 쓰시면 됩니다.
생각 과정을 화면에서 숨기는 설정은 쓰는 프로그램과 버전마다 다릅니다.

### 화면으로 쓰는 프로그램(웹 화면)에서도 같은 방법이 되나요

원리는 같습니다. 대부분의 화면 프로그램에는 **시스템 프롬프트(또는 "지시
사항")를 넣는 칸**이 있고, 거기에 같은 문장을 넣으면 처방 ②와 같은 효과입니다.
위의 Modelfile로 만든 모델을 그 프로그램에서 고르는 방법도 있습니다.

### 한국어로 답하게 하면 답의 질이 떨어지나요

영어 쪽으로 기운 모델은 **한국어 답이 영어 답보다 어색하거나 짧아지는**
경우가 있습니다. 내용이 중요하고 영어를 읽을 수 있다면 영어로 받아 두는
것도 방법이고, 한국어 품질이 중요하다면 처방 ④처럼 한국어에 강한 계열로
가는 편이 지시로 버티는 것보다 결과가 낫습니다.

정리하면 — **처음부터 영어면 모델 계열**, 코드·용어가 섞일 때만 영어면
**작은 크기**, 잘 하다가 길어진 뒤 영어면 **잘려 나간 지시**입니다. 어느
쪽이든 "한국어로"는 질문 메시지가 아니라 **시스템 프롬프트에** 두는 것이
오래가는 처방이고, 그래도 안 되면 모델을 바꾸는 게 지름길입니다.
로컬 LLM이 처음이라면 [용어 없이 읽는 시작 가이드](/posts/local-llm-start-guide.html)부터
보시면 이 글의 단어들이 더 쉽게 읽힙니다.

기준이나 동작이 실제와 다르면 [알려주세요](/contact.html). 확인 후 갱신합니다.
