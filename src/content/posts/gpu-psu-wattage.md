"5090 쓰려면 파워 몇 W짜리 사야 하나요"

커뮤니티에서 반복되는 질문입니다. 답이 갈리는 이유가 있습니다 —
**W 숫자만으로 정해지지 않기 때문입니다.**

용량이 충분한 파워를 갖고 있어도 **커넥터가 없어서 못 꽂는 경우**가 있습니다.
그게 최근 세대에서 실제로 생기는 일입니다.

## 결론부터

| 확인할 것 | 왜 |
|----------|-----|
| 1. **커넥터** | 12V-2x6 이 있는가 — **없으면 W와 무관하게 못 꽂습니다** |
| 2. 용량 | 아래 계산식 |
| 3. 규격 | ATX 3.1 이면 순간 부하를 견디게 설계돼 있습니다 |

**순서가 이렇습니다.** 1번을 안 보고 W만 맞추면 상자를 열고 나서 알게 됩니다.

## 1. 카드별 권장 용량

계산식은 이렇습니다.

```
권장 용량 = (그래픽카드 TDP + CPU + 나머지) × 1.3
              나머지 = 메인보드·SSD·팬 등, 대략 80W
```

`× 1.3` 은 여유입니다. 파워는 **부하 50~80% 구간에서 효율이 가장 좋고**,
꽉 채워 쓰면 발열과 소음이 올라갑니다.

아래는 **CPU 150W** 를 가정한 값입니다.

| 그래픽카드 | TDP | 계산값 | 권장 |
|-----------|-----|-------|------|
| **RTX 5090** | 575W | 1,047W | **1000~1200W** |
| RTX 5080 | 360W | 767W | 850W |
| RTX 5070 Ti | 300W | 689W | 750W |
| RTX 5070 | 250W | 624W | 650~750W |
| RTX 5060 Ti | 180W | 533W | 550~650W |
| RTX 5060 | 145W | 488W | 550W |
| RTX 5050 | 130W | 468W | 500~550W |

⚠️ **CPU 150W 는 가정입니다.** 상급 CPU를 쓰거나 오버클럭을 하면 더 올라갑니다.
본인 CPU의 전력 표기(TDP·PBP)를 넣어 다시 계산하시는 게 정확합니다.

```
예) 5070 + CPU 65W 저전력 구성
    (250 + 65 + 80) × 1.3 = 514W  →  550W
```

**같은 카드인데 CPU에 따라 한 단계 달라집니다.**

## 2. ⚠️ 커넥터 — 여기가 먼저 막힙니다

최근 상급 카드는 **12V-2x6** 이라는 전용 커넥터를 씁니다.
예전 8핀(PCIe 6+2) 여러 개를 꽂던 방식과 다릅니다.

```
구형 파워 850W  +  5080          →  W 는 충분한데 커넥터가 없습니다
```

**변환 어댑터가 딸려 오는 경우도 있지만**, 8핀 여러 개를 하나로 모으는 구조라
파워 쪽 배선에 부담이 갑니다. **처음부터 12V-2x6 을 내주는 파워**가 안전합니다.

### ATX 3.1 을 보세요

이 규격은 **순간적으로 크게 튀는 부하를 견디도록** 설계 기준을 정한 것입니다.
그래픽카드는 평균 소비보다 순간 소비가 훨씬 클 수 있는데, 옛 파워는 그때
보호 회로가 작동해 컴퓨터가 꺼지는 일이 있었습니다.

**W 가 충분한데 게임 중에 꺼진다면 대개 이 문제입니다.**

- 커넥터가 있는지 — **`12V-2x6` 또는 `12VHPWR` 표기**
- 규격 — `ATX 3.1` (또는 최소한 `ATX 3.0`)
- 그다음 W

## 3. 로컬 LLM은 게임과 부하가 다릅니다

여기가 이 사이트에서 따로 적어둘 부분입니다.

| | 게임 | 로컬 LLM 추론 |
|---|---|---|
| GPU 부하 | 연산부가 계속 일합니다 | **메모리를 읽는 데 묶입니다** |
| 소비 전력 | TDP 근처까지 | **TDP 상한까지는 안 갑니다** |
| 지속 시간 | 몇 시간 | **켜두면 계속** |

**로컬 LLM은 대역폭에 묶이는 작업**이라 연산부가 노는 구간이 생깁니다.
그래서 같은 카드로 게임할 때보다 소비가 낮습니다 —
[왜 대역폭이 속도를 정하는지](/posts/local-llm-without-gpu.html)에 계산해 뒀습니다.

> ⚠️ **"몇 % 낮다" 는 적지 않겠습니다.** 구조상 낮은 것은 맞지만
> 측정하지 않았습니다. 전기요금 계산에서도 같은 이유로
> [TDP 를 상한으로만 썼습니다](/posts/local-llm-power-cost.html).

**그래서 파워 기준은 게임용과 같게 잡으면 됩니다.** 여유가 남을 뿐입니다.
다만 **오래 켜두는 쪽**이라 효율과 소음이 더 중요해집니다 —
소음 쪽은 [CPU 쿨러 판정](/posts/cpu-stock-cooler.html)도 같은 결의 문제입니다.

## 4. 두 장을 꽂는다면

TDP 가 그대로 더해집니다.

```
5060 Ti 두 장  →  180 × 2 = 360W
(360 + 150 + 80) × 1.3 = 767W  →  850W
```

커넥터 개수도 함께 봐야 합니다. **한 장 기준으로 산 파워는 두 번째 카드에
꽂을 커넥터가 없는 경우가 많습니다.**

다만 **두 장이 생각만큼 좋지 않습니다** —
[VRAM이 합쳐지나요](/posts/multi-gpu-local-llm.html)에 정리했습니다.
전력과 발열은 두 배인데 속도는 합쳐지지 않습니다.

## 5. 노트북은 해당 없습니다

노트북은 어댑터가 정해져 나옵니다. 대신 다른 것이 걸립니다 —
어댑터 전력과 USB-C 충전 한계입니다.
[개발용 노트북 배터리](/posts/laptop-battery-dev.html)에 적었습니다.

## 자주 묻는 질문

### 권장보다 큰 파워를 사면 전기를 더 먹나요

**아닙니다.** 파워 용량은 상한이고, 실제 소비는 부품이 쓰는 만큼입니다.
1000W 파워를 달아도 300W 를 쓰면 300W 만 나갑니다.
오히려 부하율이 낮으면 효율이 좋은 구간에 들어갑니다 —
[전기 사용을 실제로 정하는 것](/posts/psu-capacity-power-draw.html)은
따로 정리했습니다.

### 지금 파워 W 를 어디서 확인하나요

파워 본체 옆면 스티커에 적혀 있습니다. 케이스를 열어야 보이는 경우가 많습니다.
**모델명을 검색하면 커넥터 구성과 규격까지 나옵니다** — W 만 보지 마세요.

### 어댑터로 8핀을 모아 쓰면 안 되나요

동작은 합니다. 카드에 딸려 오는 정품 어댑터라면 규격 안에서 쓰는 것입니다.
다만 **여러 갈래를 하나로 모으는 구조**라 파워 쪽 배선과 접점에 부담이 갑니다.
새로 사실 거면 처음부터 12V-2x6 이 있는 쪽을 권합니다.

### 게임은 되는데 로컬 LLM 돌릴 때 꺼집니다

**순서가 반대라 이상해 보이지만 가능합니다.** 로컬 LLM은 오래 켜두는 작업이라
파워가 뜨거워진 상태로 계속 갑니다. 보호 회로는 온도에도 반응합니다.
케이스 통풍과 파워 나이를 함께 보세요.

### 80 PLUS 등급은 봐야 하나요

효율 등급입니다. 높으면 같은 일에 전기를 덜 쓰고 발열이 적습니다.
**오래 켜두는 용도라면 값어치가 있고, 가끔 쓰는 용도라면 브론즈로 충분합니다** —
갈림 조건과 회수 기간 계산은
[80PLUS 등급, 골드에 웃돈 낼 가치](/posts/psu-80plus.html)에 따로 정리했습니다.

### 파워는 나중에 바꿀 수 있나요

됩니다. 데스크톱에서 **가장 바꾸기 쉬운 부품 중 하나**입니다.
다만 카드를 먼저 사고 파워가 안 맞으면 그날 컴퓨터를 못 씁니다.
**카드와 함께 확인하세요.**

## 정리

1. **커넥터를 먼저 보세요.** `12V-2x6` 이 없으면 W 와 무관하게 못 꽂습니다
2. 용량은 **(GPU TDP + CPU + 80W) × 1.3** 입니다
3. **CPU 에 따라 한 단계 달라집니다.** 본인 값으로 계산하세요
4. `ATX 3.1` 은 순간 부하 기준입니다. W 가 충분한데 꺼지면 대개 이 문제입니다
5. **로컬 LLM은 TDP 상한까지 안 갑니다.** 게임 기준으로 잡으면 여유가 남습니다
6. 두 장은 **TDP 도 커넥터도 두 배**입니다
