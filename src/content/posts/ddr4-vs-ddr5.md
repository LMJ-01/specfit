램을 사려고 보면 `DDR4`와 `DDR5`가 나뉘어 있습니다. 숫자가 크면 좋은 거니까 DDR5를 사야 하나 싶은데,

**대부분의 경우 고를 수 있는 게 아닙니다.** 메인보드가 이미 정해놨습니다.

## 결론부터

| 질문 | 답 |
|------|-----|
| 뭘 골라야 하나 | **메인보드가 받는 것.** 선택지가 아닙니다 |
| 섞어 쓸 수 있나 | **불가능합니다.** 슬롯 모양이 다릅니다 |
| 성능 차이는 | 대역폭 약 1.75배 (DDR5-5600 vs DDR4-3200) |
| 개발 작업에서 체감되나 | **거의 안 됩니다** |
| 로컬 LLM에서는 | CPU로 돌릴 때만 의미 있습니다 |
| 지금 새로 맞춘다면 | **DDR5.** DDR4는 줄어드는 중입니다 |

## 1. 애초에 안 꽂힙니다

가장 먼저 알아야 할 것이고, 이걸로 고민의 90%가 끝납니다.

**DDR4와 DDR5는 슬롯의 홈 위치가 다릅니다.** 억지로 꽂으면 안 들어가고, 힘을 주면 부러집니다.

```
메인보드가 DDR4 →  DDR4 만 꽂힙니다
메인보드가 DDR5 →  DDR5 만 꽂힙니다
```

**한 메인보드가 둘 다 받는 경우는 없습니다.** (일부 보드가 "둘 중 하나를 고른 버전"으로 따로 나올 뿐, 한 보드에 둘 다 꽂히지는 않습니다.)

### 내 컴퓨터가 뭔지 확인하는 법

`Ctrl` + `Shift` + `Esc` → **성능** 탭 → **메모리**.
오른쪽에 `DDR4` 또는 `DDR5`가 적혀 있습니다. **속도와 사용된 슬롯 수도 같이 나옵니다.**

노트북이면 대개 제품 사양에 적혀 있습니다.

## 2. 그럼 언제 고르게 되나 — 새로 맞출 때

메인보드와 CPU를 새로 살 때만 선택이 생깁니다. 그리고 그 선택도 **CPU를 고르면 따라옵니다.**

**현행 플랫폼은 DDR5 전용입니다.** AMD AM5(라이젠 9000 계열), 인텔 LGA1851(코어 울트라 200 계열) 모두 DDR4를 받지 않습니다.

즉 **요즘 CPU를 고르면 DDR5로 자동 결정됩니다.** DDR4를 쓰려면 일부러 이전 세대 플랫폼을 골라야 합니다.

### ⚠️ DDR4는 줄어드는 중입니다

제조사들이 생산 라인을 DDR5와 AI 서버용 메모리로 옮기고 있습니다. 마이크론은 DDR4 종료 수순을 공표했고, 나머지 두 곳도 같은 방향입니다.

**이게 뜻하는 것:**

- 새로 맞추면서 DDR4 플랫폼을 고르는 건 **막다른 길**입니다
- 나중에 증설하려 할 때 물건이 없거나 비쌀 수 있습니다
- **이미 DDR4를 쓰고 계시다면 당장 바꿀 이유는 없습니다.** 잘 돌아갑니다

> 언제 완전히 끊길지는 아무도 모릅니다. **전망이지 확정이 아닙니다.**
> 다만 방향은 한쪽입니다.

## 3. 성능 차이 — 대역폭 1.75배

숫자로 보면 이렇습니다. 대역폭은 계산됩니다.

```
대역폭 = 클럭 × 8바이트 × 채널 수

DDR5-5600 듀얼채널  =  5600 × 8 × 2  =  약 89.6 GB/s
DDR4-3200 듀얼채널  =  3200 × 8 × 2  =  약 51.2 GB/s
```

**약 1.75배입니다.** 숫자만 보면 큰 차이 같습니다.

{{FIG:cpu-vs-gpu-bandwidth}}

그런데 위 그림에서 보시면, **둘 다 그래픽카드에 비하면 바닥 근처에 있습니다.** 이게 뒤에 나올 이야기의 핵심입니다.

### 개발 작업에서는 체감이 거의 없습니다

램 대역폭이 병목인 작업이 별로 없기 때문입니다.

| 작업 | 실제 병목 |
|------|---------|
| 빌드·컴파일 | **CPU 코어 수** |
| `npm install` | 디스크의 작은 파일 처리 |
| IDE·브라우저 | **램 용량** (대역폭 아님) |
| 도커 컨테이너 | 램 용량 |

**부족하면 문제가 되는 건 용량이지 속도가 아닙니다.** 16GB가 모자라서 느린 것을 DDR5로 바꿔서 해결할 수는 없습니다.

우선순위는 이렇습니다.

```
용량  →  듀얼 채널  →  규격(DDR4/DDR5)  →  클럭
```

**규격은 네 개 중 세 번째입니다.** 그리고 어차피 메인보드가 정합니다.

## 4. 로컬 LLM에서는 — 한 경우만 의미 있습니다

**모델이 VRAM에 다 들어가면 시스템 램은 거의 놀고 있습니다.** 이때는 DDR4든 DDR5든 차이가 없습니다.

의미가 생기는 건 **VRAM을 넘겨서 CPU가 일을 떠맡을 때**입니다. 그때는 시스템 램의 대역폭이 그대로 생성 속도가 됩니다.

```
전부 VRAM 에 올라감   →  DDR4 든 DDR5 든 똑같음
CPU 로 넘어감         →  DDR5 가 1.75배 유리
GPU 없이 CPU 로만     →  DDR5 가 확실히 유리
```

**다만 그 1.75배도 그래픽카드 앞에서는 작습니다.** 가장 저렴한 신품 그래픽카드(RTX 5060)가 448 GB/s인데, DDR5-5600은 89.6 GB/s입니다. **5배 차이입니다.**

→ **DDR5로 바꾸려고 메인보드와 CPU까지 교체할 정도의 이득은 아닙니다.**
   그 돈이면 그래픽카드를 보는 게 낫습니다.

자세한 계산은 [그래픽카드 없이 로컬 LLM](/posts/local-llm-without-gpu.html)에 있습니다.

## 5. 규격보다 훨씬 중요한 것 — 듀얼 채널

**같은 규격 안에서 대역폭을 두 배로 만드는 방법이 있습니다.** 두 장으로 나눠 꽂는 것입니다.

| 구성 | 대역폭 |
|------|-------|
| DDR4-3200 **16GB 두 장** | 51.2 GB/s |
| DDR4-3200 32GB 한 장 | 25.6 GB/s |
| DDR5-5600 32GB 한 장 | 44.8 GB/s |

**DDR4 두 장이 DDR5 한 장보다 대역폭이 높습니다.**

규격을 올리는 것보다 **같은 용량을 두 장으로 나누는 게** 더 확실하고 돈도 덜 듭니다.
메인보드 슬롯이 4개면 보통 **2번·4번**에 꽂습니다. 설명서를 확인하세요.

**노트북도 같습니다.** 슬롯이 두 개인데 한 장만 꽂혀 있는 경우가 많아서
[노트북 램 교체](/posts/laptop-ram-upgrade.html)에서는 이게 가장 남는 장사입니다.

## 자주 묻는 질문

### DDR4 컴퓨터를 DDR5로 업그레이드할 수 있나요

램만 바꿔서는 안 됩니다. **메인보드와 CPU까지 함께 바꿔야 합니다.**
사실상 컴퓨터를 새로 맞추는 것이라, 램 때문에 하는 결정은 아닙니다.

### 지금 DDR4를 쓰는데 손해인가요

아닙니다. 잘 돌아갑니다. 개발 작업에서 체감 차이가 거의 없습니다.
다만 **나중에 증설하려면 물건이 줄어들고 있다**는 점은 알아두시는 게 좋습니다.

### DDR5도 속도가 여러 가지던데요

5600, 6000, 6400 같은 숫자입니다. 높을수록 대역폭이 큽니다.
다만 **개발 작업에서 체감 차이는 작고**, CPU와 메인보드가 지원하는 범위 안에서만 동작합니다.
**용량과 듀얼 채널을 먼저 챙기시고, 클럭은 마지막입니다.**

⚠️ **그리고 그 숫자는 켜야 나옵니다.** 표기 속도는 규격 밖이라 기본으로 안 켜지고,
아무것도 안 하면 DDR5 는 4800 으로 돕니다 —
[램 XMP·EXPO](/posts/ram-xmp-expo.html)에 확인법을 적었습니다.

### 노트북도 DDR4/DDR5로 나뉘나요

나뉩니다. 다만 노트북은 **LPDDR5X 같은 저전력 규격**을 쓰는 경우가 많고, 이건 대개 납땜이라 교체가 안 됩니다.
확인법은 [노트북 램 나중에 못 늘립니다](/posts/laptop-ram-onboard-lpcamm2.html)에 있습니다.

### 용량이 다른 두 장을 꽂아도 되나요

동작은 합니다. 다만 **겹치는 만큼만 듀얼 채널로 동작**하는 경우가 많아 이득을 온전히 못 받습니다.
가능하면 같은 제품 두 장이 안전합니다.

## 정리

1. **고를 수 있는 게 아닙니다.** 메인보드가 정하고, 슬롯이 달라 안 바뀝니다
2. **현행 플랫폼은 DDR5 전용**입니다. 새로 맞추면 자동으로 DDR5입니다
3. 대역폭은 **약 1.75배**지만 개발 작업에서는 **체감이 거의 없습니다**
4. 로컬 LLM에서는 **CPU로 넘어갈 때만** 의미 있고, 그마저 그래픽카드의 1/5입니다
5. 규격보다 **듀얼 채널**이 확실합니다. DDR4 두 장이 DDR5 한 장보다 빠릅니다
6. **DDR4는 줄어드는 중**입니다. 새로 맞추면서 고를 이유는 없습니다
