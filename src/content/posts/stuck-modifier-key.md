파일을 열려고 더블클릭했는데 파일은 안 열리고 **속성 창**이 뜹니다. 다시 해도
마찬가지입니다. 마우스가 고장 났나 싶고, 검색하면 "파일 연결 프로그램을
다시 지정하라"는 답이 나옵니다.

그런데 이 증상은 대부분 마우스도, 파일 연결도 아닙니다. 윈도우에서 **Alt를
누른 채 더블클릭하면 속성 창이 열리게** 되어 있어서, 윈도우가 지금 **Alt 키를
누르고 있는 것으로 알고 있는 상태**라는 뜻입니다.

## 결론부터

| 증상 | 눌린 채로 잡힌 키 |
|------|----------------|
| 더블클릭하면 **속성 창**이 열림 | **Alt** |
| 마우스 휠을 굴리면 **확대·축소**됨, 클릭하면 **여러 개가 같이 선택**됨 | **Ctrl** |
| 글자가 **대문자·특수문자**로 나옴, 클릭하면 **범위가 선택**됨 | **Shift** |
| 키를 누를 때마다 **창이 열리거나 단축키가 실행**됨 | **Win** |
| 푸는 순서 | 양쪽 키 여러 번 누르기 → 고정 키 확인 → 화면 키보드 → 다른 키보드 |

## 왜 이런 일이 생기나

키보드는 키를 **누를 때**와 **뗄 때** 각각 신호를 보냅니다. 그런데 뗄 때 신호가
중간에 빠지면, 윈도우는 그 키가 아직 눌려 있다고 생각합니다. 그러면 마우스
동작에 그 키 조합이 덧붙어서 엉뚱한 일이 일어납니다.

- **무선 키보드**가 키를 누른 순간 잠깐 끊겼던 경우
- **원격 접속·가상 머신** 창에서 Alt+Tab 같은 조합을 쓰고 빠져나온 경우
- 키 아래 이물질이나 노화로 **키가 실제로 덜 올라온** 경우
- 접근성의 **고정 키**가 켜져서, 한 번 누른 Alt·Ctrl·Shift가 다음 동작까지 유지되는 경우

## 푸는 순서

1. **그 키를 양쪽 다 여러 번** 누릅니다. Alt라면 왼쪽 Alt와 오른쪽 Alt(한/영 키
   자리인 키보드도 있습니다)를 각각 몇 번씩 눌렀다 뗍니다. 빠졌던 "뗌" 신호가
   들어가면서 대부분 여기서 풀립니다
2. **고정 키가 켜져 있지 않은지** 봅니다. 설정 → 접근성 → 키보드의 **고정 키**가
   켜져 있으면 끕니다. Shift를 연달아 누르다 실수로 켜지는 경우가 많습니다.
   Shift·Ctrl·Alt를 누를 때 **삑 소리**가 난다면 이 기능이 켜진 신호입니다 —
   [키 누를 때 삑 소리](/posts/keyboard-beep-sound.html)
3. **화면 키보드**를 띄워 봅니다. 눌린 것으로 잡힌 수정키가 다른 색으로 표시되는
   경우가 있어, 어느 키가 범인인지 확인하는 데 도움이 됩니다
4. **다른 키보드를 꽂아** 보거나, 무선이라면 잠깐 꺼서 연결을 끊어 봅니다.
   원래 키보드를 뺐을 때 증상이 사라지면 그 키보드의 키가 실제로 걸린 쪽입니다

계속 되풀이된다면 키가 물리적으로 걸리는 쪽이라, 키캡 아래 청소와 키 격리는
[일부 키가 안 될 때의 층 가르기](/posts/keyboard-some-keys-dead.html) 순서와 같습니다.

## 형제 증상들

- **Ctrl** — 브라우저나 문서에서 휠을 굴렸을 뿐인데 화면이 커졌다 작아졌다 하고,
  파일을 하나 클릭했는데 여러 개가 선택된다면 Ctrl입니다. 바탕화면 아이콘이 갑자기
  커지는 것도 같은 원리입니다 — [아이콘이 갑자기 커질 때](/posts/desktop-icons-missing.html)
- **Shift** — 한글이 쌍자음으로, 숫자가 특수문자로 나오고, 클릭할 때마다 범위가
  잡힌다면 Shift입니다
- **Win** — 글자를 칠 때마다 시작 메뉴나 엉뚱한 창이 열린다면 Win 키입니다

## 자주 묻는 질문

### 마우스를 바꿔야 하나요

더블클릭 자체가 문제라면 마우스지만, **속성 창이 뜨는** 건 마우스가 아니라 키보드
쪽 신호입니다. 반대로 한 번 눌렀는데 **두 번 눌린 것처럼** 동작한다면 그건 마우스
접점 문제입니다 — [한 번 눌렀는데 더블클릭이 될 때](/posts/mouse-double-click.html).

### 글자를 칠 때 뒤 글자가 지워지는 것도 같은 문제인가요

비슷해 보이지만 다른 갈래입니다 — 덮어쓰기 모드나 입력기 문제일 수 있어
[타자 치면 글자가 지워질 때](/posts/typing-deletes-text.html)에서 따로 가릅니다.

### 재부팅하면 풀리던데요

재부팅하면 키 상태가 처음부터 다시 잡히니 풀리는 게 맞습니다. 다만 위의 1번
(양쪽 키 여러 번 누르기)이 훨씬 빠르고, 자주 되풀이된다면 재부팅보다 원인(무선 연결·
원격 접속·키 걸림)을 찾는 쪽이 낫습니다.

## 정리

1. 더블클릭하면 속성 창이 뜨는 건 대개 **Alt가 눌린 채로 잡힌** 상태입니다
2. 휠이 확대·축소되면 **Ctrl**, 대문자·범위 선택이면 **Shift**, 창이 열리면 **Win**입니다
3. 먼저 **그 키를 양쪽 다 여러 번** 눌러 풉니다
4. 안 풀리면 **고정 키 → 화면 키보드 → 다른 키보드** 순서로 봅니다
5. 되풀이되면 **키가 실제로 걸린** 쪽이라 키보드 격리로 갑니다
