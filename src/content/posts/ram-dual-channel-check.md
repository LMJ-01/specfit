램 이야기가 나올 때마다 이 사이트는 **"우선순위는 용량 → 듀얼 채널 → 클럭"**
이라고 적었습니다.

그런데 정작 **내 컴퓨터가 지금 듀얼 채널로 돌고 있는지 확인하는 방법**은
어디에도 안 적었습니다. 이 글이 그 확인법입니다.

두 장을 꽂았다고 끝이 아닙니다. **같은 채널에 몰아 꽂으면 두 장이어도
싱글 채널로 돕니다.** 조립을 맡겼든 직접 했든, 한 번은 확인할 값어치가
있습니다 — 확인은 1분이고, 아니었을 때 얻는 속도는 공짜이기 때문입니다.

## 왜 확인하나 — 대역폭이 두 배 차이

듀얼 채널은 램 두 장을 **동시에** 읽고 쓰는 구성입니다. 대역폭이 두 배가
됩니다.

```
DDR5-5600 싱글 채널   5600 × 8바이트          = 44.8 GB/s
DDR5-5600 듀얼 채널   5600 × 8바이트 × 2채널  = 89.6 GB/s
```

체감이 갈리는 지점도 분명합니다.

| 작업 | 싱글이면 |
|------|---------|
| 웹서핑·문서 작업 | 차이를 느끼기 어렵습니다 |
| 내장그래픽 게임·작업 | 눈에 띄게 느립니다 — 내장그래픽은 시스템 램을 씁니다 |
| CPU로 LLM 추론 | **속도가 거의 절반**이 됩니다 |
| VRAM 넘쳐 오프로딩 | 넘어간 몫을 램이 받는 속도가 절반이 됩니다 |

[GPU 없이 로컬 LLM 돌리기](/posts/local-llm-without-gpu.html)의 속도 계산이
전부 듀얼 채널 전제입니다. 싱글이면 그 표의 절반으로 읽어야 합니다.

## 확인법 1 — CPU-Z (확실합니다)

`cpuid.com` 에서 CPU-Z를 받아 실행하고 **Memory 탭**을 봅니다.
**Channel #** 항목이 답인데, **표기가 규격·버전에 따라 달라서** 읽는 법이
필요합니다. 여기서 다들 한 번씩 헷갈립니다.

| 내 램 | 듀얼 채널이면 | 싱글이면 |
|-------|-------------|---------|
| DDR4 | `2 x 64bit` (구버전은 `Dual`) | `1 x 64bit` (`Single`) |
| DDR5 | **`4 x 32bit`** | `2 x 32bit` |

**DDR5에서 "4 x 32bit"가 뜨는 건 정상이고, 그게 듀얼 채널입니다.**
DDR5는 한 장 안에 32비트 통로(서브채널)가 2개씩 들어 있어서,
두 장이면 32비트 × 4로 표시됩니다. "2가 아니라 4라니 뭔가 이상하다"고
검색하게 되는 지점인데, 이상한 게 아닙니다.

## 확인법 2 — HWiNFO

HWiNFO를 설치해 요약(Summary) 화면을 열면 메모리 항목에
**모드(Memory Mode)** 가 "듀얼 채널(Dual Channel)"로 표기됩니다.
CPU-Z의 비트 표기보다 말로 나와서 읽기는 이쪽이 쉽습니다.

## 확인법 3 — 작업 관리자 (장수만 나옵니다)

윈도우 작업 관리자 → 성능 → 메모리에서 **"슬롯 사용: 2/4"** 를 볼 수
있습니다. 다만 이건 **몇 장 꽂혀 있는지**만 알려줍니다.

**두 장이 같은 채널에 꽂혀 있어도 "2/4"로 나옵니다.** 채널이 어떻게
도는지는 여기서 알 수 없으므로, 장수 확인용으로만 쓰고 판정은
CPU-Z나 HWiNFO로 하세요.

## 싱글로 나왔다면 — 고치는 법

**전원을 끄고 램 위치를 옮기면 끝입니다.** 새로 살 것이 없습니다.

- 슬롯이 4개인 보드에서 두 장이라면 보통 **2번·4번**(CPU에서 두 번째,
  네 번째)에 꽂습니다. 다만 보드마다 지정 슬롯이 다르므로
  **메인보드 설명서의 메모리 구성표가 기준**입니다. 설명서를 잃었다면
  제조사 홈페이지에서 모델명으로 받을 수 있습니다.
- 옮긴 뒤 다시 CPU-Z로 확인하면 표기가 바뀌어 있어야 합니다.

**램이 한 장뿐이라면** 옮겨도 싱글입니다. 같은 규격·같은 용량으로 한 장을
더해 두 장을 만드는 것이 가장 싼 업그레이드입니다. 기존 램과 다른 제품을
섞으면 낮은 쪽 클럭에 맞춰지고 드물게 불안정할 수 있어,
**가능하면 같은 제품 두 장**이 안전합니다 — 용량까지 다른 조합의
동작은 [혼용 글](/posts/mixed-ram-capacity.html)에 따로 정리했습니다.

## 자주 묻는 질문

### 4장을 꽂으면 쿼드 채널이 되나요

안 됩니다. **일반 데스크톱 CPU는 채널이 2개**라서, 4장을 꽂아도
채널당 2장씩 나눠 들어갈 뿐 대역폭은 두 장일 때와 같습니다.
4장은 **용량이 더 필요할 때** 고르는 구성이고, 오히려 4장을 꽂으면
높은 클럭(XMP)에서 안정성이 떨어질 수 있습니다.
같은 용량이라면 **큰 것 2장이 작은 것 4장보다 낫습니다.**

### 용량이 다른 두 장(8GB+16GB)도 듀얼이 되나요

대체로 **겹치는 만큼만** 듀얼로 동작합니다(8+8은 듀얼, 남는 8GB는 싱글).
아예 안 되는 것보다는 낫지만, 온전한 듀얼은 아닙니다. 보드·CPU에 따라
동작이 다를 수 있어서, 제대로 하려면 같은 용량 두 장이 맞습니다.

### 노트북도 확인할 수 있나요

CPU-Z·HWiNFO 모두 노트북에서도 그대로 동작합니다. 다만 얇은 노트북은
램이 납땜(온보드)되어 있거나 온보드+슬롯 혼합이라, 싱글로 나와도
손댈 수 있는 폭이 다릅니다. 슬롯이 있는 모델인지부터
[노트북 램 업그레이드](/posts/laptop-ram-upgrade.html)에서 확인하세요.

### 듀얼로 만들었는데 클럭이 낮게 나옵니다

그건 채널이 아니라 **클럭 설정** 문제입니다. 램은 XMP를 켜기 전까지
기본 클럭으로 돕니다. [XMP·EXPO 켜는 법](/posts/ram-xmp-expo.html)이
바로 다음 확인 항목입니다 — 우선순위 순서 그대로입니다.

### 게임이나 LLM이 아니면 신경 안 써도 되나요

웹서핑·문서 작업 위주라면 체감 차이가 작은 건 사실입니다. 다만 확인이
1분이고 고치는 데 돈이 안 들어서, **어느 쪽이든 확인해 두고 넘어가는 편**을
권합니다.

## 정리

1. 두 장 꽂았다고 듀얼이 아닙니다. **같은 채널에 몰리면 싱글로 돕니다**
2. **CPU-Z Memory 탭**으로 확인합니다 — DDR5는 듀얼이 `4 x 32bit`로
   표시됩니다. 4가 정상입니다
3. 작업 관리자의 "슬롯 사용"은 **장수만** 알려줍니다. 판정은 못 합니다
4. 싱글이었다면 **램을 옮겨 꽂는 것**으로 끝납니다. 보통 2번·4번,
   기준은 메인보드 설명서입니다
5. 확인했다면 다음은 **XMP**입니다. 용량 → 듀얼 채널 → 클럭, 이 순서입니다

램 용량 자체가 고민이라면 [램 16GB vs 32GB](/posts/ram-16gb-vs-32gb.html)부터,
같은 32GB 를 몇 장으로 만들지는 [16×2 vs 32×1](/posts/ram-16x2-vs-32x1.html)에서
가르세요.

표기나 동작이 실제와 다르면 [알려주세요](/contact.html). 확인 후 갱신합니다.
