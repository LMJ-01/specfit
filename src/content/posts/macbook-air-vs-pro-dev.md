개발용 맥을 고를 때 에어와 프로 사이에서 오래 고민하게 됩니다.
CPU 성능 차이는 리뷰가 많은데, **정작 개발에서 갈리는 지점은 다른 데 있습니다.**

## 결론부터

| | 맥북 에어 | 맥북 프로 |
|---|---|---|
| 칩 | M5 | M5 / M5 Pro / M5 Max |
| 메모리 | 16 · 24 · **32GB (천장)** | 16GB ~ **128GB** |
| 대역폭 | 153 GB/s | 153 / 307 / 460~614 GB/s |
| 팬 | **없음** | 있음 |
| 화면 | 13" · 15" | 14" · 16" |

**개발에서 갈리는 건 세 가지입니다.**

1. **메모리 천장** — 에어는 32GB에서 끝납니다
2. **대역폭** — 로컬 LLM을 하면 두 배 차이가 그대로 체감됩니다
3. **팬** — 오래 돌리는 작업에서 갈립니다

## 1. 메모리 천장 — 이게 가장 큽니다

**에어는 32GB가 최대입니다.** 프로는 M5 Pro로 64GB, M5 Max로 128GB까지 갑니다.

맥은 **나중에 메모리를 못 늘립니다.** 살 때 정해지고 그걸로 끝입니다.
그래서 이 천장이 실질적인 수명이 됩니다.

| 작업 | 필요 메모리 |
|------|-----------|
| 웹 개발, 일반 코딩 | 16GB |
| 도커·가상머신 병행 | **24~32GB** |
| 로컬 LLM 14B급 | 24GB |
| 로컬 LLM 32B급 | **48GB** |
| 로컬 LLM 70B급 | **128GB** |

**32B 이상을 넘본다면 에어로는 안 됩니다.**
자세한 기준은 [맥 통합메모리 글](/posts/mac-unified-memory-local-llm.html)에 있습니다.

## 2. 대역폭 — 로컬 LLM에서만 크게 갈립니다

맥은 램이 VRAM 역할까지 하므로, **대역폭이 곧 생성 속도**입니다.

{{FIG:bandwidth}}

| 칩 | 대역폭 | 에어 대비 |
|----|-------|---------|
| M5 (에어·프로 14") | 153 GB/s | 기준 |
| M5 Pro | 307 GB/s | **2배** |
| M5 Max (GPU 32코어) | 460 GB/s | 3배 |
| M5 Max (GPU 40코어) | 614 GB/s | 4배 |

**같은 모델을 돌려도 M5 Pro가 두 배 빠릅니다.**

다만 **일반 개발 작업에서는 이 차이가 거의 안 느껴집니다.**
컴파일이나 빌드는 메모리 대역폭보다 CPU 코어 수에 묶이기 때문입니다.
대역폭이 결정적인 건 로컬 LLM처럼 **큰 데이터를 반복해서 읽는 작업**입니다.

> **M5 Max는 같은 이름 안에서 대역폭이 갈립니다.** GPU 코어 수(32 vs 40)가 정합니다.
> 메모리 용량이 아닙니다. 구성표에서 GPU 코어 수를 확인하세요.

## 3. 팬 — 오래 돌릴 때

**에어에는 팬이 없습니다.** 조용하고 가볍지만, 열이 쌓이면 성능을 낮춰 버팁니다.

| 작업 | 에어에서 |
|------|---------|
| 편집, 짧은 빌드 | 문제없습니다 |
| 긴 컴파일 | 후반에 느려질 수 있습니다 |
| **로컬 LLM 장시간** | **영향을 받습니다** |

로컬 LLM은 몇 분씩 연속으로 돌리는 작업이라 여기 해당합니다.
**가끔 쓸 거면 상관없고, 상시로 쓸 거면 프로가 맞습니다.**

## 그래서 누가 뭘 사야 하나

**에어 16GB — 권하지 않습니다**

일반 코딩은 되지만 도커를 띄우면 금방 찹니다.
로컬 LLM도 7~8B가 상한입니다. 개발용으로는 24GB부터 보세요.

**에어 24GB — 가장 무난한 선택**

일반 개발과 14B급 로컬 LLM이 둘 다 됩니다.
**대부분의 개발자에게는 여기가 정답**입니다. 가볍고 조용합니다.

**에어 32GB — 에어의 상한**

도커를 여러 개 띄우거나 22B급까지 넘볼 때입니다.
다만 **이 값이면 프로 24GB와 비교**해 보세요. 대역폭이 두 배입니다.

**프로 M5 Pro — 로컬 LLM을 진지하게 할 때**

대역폭 307 GB/s에 64GB까지 갑니다. 팬도 있습니다.
**32B급을 상시로 쓸 계획이면 여기부터**입니다.

**프로 M5 Max — 70B를 노릴 때만**

128GB 구성은 70B 모델을 돌리기 위한 것입니다.
그 계획이 없다면 **돈이 남는 게 아니라 그냥 남습니다.**

## 에어를 사도 되는 경우

**"로컬 LLM은 안 할 건데요"**

그러면 에어로 충분합니다. 일반 개발에서 에어와 프로의 체감 차이는 크지 않습니다.
메모리만 24GB 이상으로 맞추세요.

**"들고 다녀야 합니다"**

에어가 가볍고 배터리가 좋습니다. 이동성은 스펙표에 안 나오지만 매일 체감됩니다.

**"조용한 게 중요합니다"**

팬이 없다는 건 단점이자 장점입니다.

## 윈도우 노트북과 비교하면

| | 맥 | 윈도우 + 전용 GPU |
|---|---|---|
| 최대 메모리 | **128GB** | 24GB (5090 노트북) |
| 대역폭 | 153~614 GB/s | 448~896 GB/s |
| 70B 모델 | **가능** | 불가 |
| 같은 모델 속도 | 느린 편 | **빠른 편** |

**용량이 필요하면 맥, 속도가 필요하면 윈도우**입니다.
노트북 GPU 쪽 기준은 [로컬 LLM 되는 노트북 고르기](/posts/local-llm-laptop-choose.html)에 있습니다.

## 자주 묻는 질문

### 에어 32GB와 프로 24GB 중 어느 쪽인가요

**로컬 LLM을 한다면 프로 24GB**입니다. 대역폭이 153 대 307로 두 배입니다.
**용량이 더 필요하면 에어 32GB**입니다. 22B급을 넘보려면 32GB가 필요합니다.

같은 값이면 **무엇을 돌릴지**로 정하세요.

### 나중에 메모리를 늘릴 수 있나요

**없습니다.** 애플 실리콘은 메모리가 칩 패키지에 붙어 있습니다.
부족하면 기기를 바꾸는 수밖에 없어서, 애매하면 한 단계 위가 안전합니다.

### 13인치와 15인치 에어는 성능이 같나요

같은 M5 칩입니다. 화면 크기와 무게가 다릅니다.
**코딩에는 세로 픽셀이 중요**하니 화면 사양을 확인하세요 —
기준은 [코딩용 모니터 글](/posts/coding-monitor-resolution.html)에 있습니다.

### 프로 14인치 M5 기본형은요

칩은 에어와 같은 M5(153 GB/s)입니다. 대역폭 이득이 없습니다.
**팬과 화면 때문에 사는 구성**이라고 보시면 됩니다.
대역폭이 목적이면 M5 Pro부터입니다.

### 개발용으로 16GB면 정말 부족한가요

일반 웹 개발만 하면 됩니다. 다만 도커·에뮬레이터·브라우저 탭이 겹치면 좁습니다.
**나중에 못 늘린다**는 점을 감안하면 24GB부터가 안전합니다.
기준은 [램 16GB vs 32GB](/posts/ram-16gb-vs-32gb.html)에 정리했습니다.

## 정리

1. 갈리는 건 **메모리 천장 · 대역폭 · 팬** 셋입니다
2. **에어는 32GB가 천장**입니다. 32B 이상 모델은 못 넘봅니다
3. **M5 Pro는 대역폭이 두 배**(307)입니다. 로컬 LLM에서만 크게 체감됩니다
4. 일반 개발만 한다면 **에어 24GB로 충분**합니다
5. **나중에 못 늘립니다.** 애매하면 한 단계 위를 고르세요
