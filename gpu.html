로컬 LLM·딥러닝용 그래픽카드를 VRAM 기준으로 고릅니다. 어떤 카드로 몇 B 모델이 돌아가는지 계산기로 바로 확인할 수 있습니다.

처음이면 — 용어 없이 읽는 로컬 LLM 시작 가이드

  • GPU 그래픽카드 인식이 안 될 때 — "어디까지 보이는지"가 갈래를 알려줍니다 그래픽카드가 장치 관리자에 아예 없는 것, 알 수 없는 장치로 뜨는 것, 잡혀 있는데 게임이 내장그래픽만 쓰는 것은 전부 다른 문제입니다. 인식이 어느 층에서 끊겼는지부터 가르면 장착·전원·드라이버·선택 중 어느 갈래인지가 정해집니다.
  • GPU 컴퓨터에서 타는 냄새가 날 때 — 진단보다 전원 차단이 먼저입니다 본체에서 탄내나 매캐한 냄새가 나면 "작동은 잘 되는데"라는 이유로 계속 쓰기 쉽습니다. 그런데 이 증상만은 순서가 다릅니다. 전원부터 끊고, 끈 상태에서 냄새의 종류와 위치로 갈래를 가르는 판정 — 그리고 다시 켜도 되는 기준까지 정리했습니다.
  • GPU 프레임은 잘 나오는데 끊기는 게임 — 평균이 아니라 간격의 문제입니다 프레임 수치는 높은데 화면이 뚝뚝 끊기는 느낌이 드는 경우가 있습니다. 부드러움을 정하는 것은 평균 프레임이 아니라 프레임 사이 간격의 고름이라서입니다. 끊김의 세 갈래를 가르는 판정 순서를 정리했습니다.
  • GPU 케이스 옆판 열고 쓰면 안 되나 — 진단용으로는 최고, 상시 운용으로는 손해입니다 온도가 걱정되면 옆판을 열어두고 싶어집니다. 그런데 열어서 시원해지는 컴퓨터가 있고 오히려 나빠지는 자리도 있습니다. 옆판 열기의 진짜 쓸모는 상시 해법이 아니라 진단 도구라는 것 — 판정과 대가를 정리했습니다.
  • GPU 게임하다 컴퓨터가 꺼진다면 — 꺼진 모양이 범인을 알려줍니다 게임 중에만 컴퓨터가 툭 꺼지거나 혼자 재부팅되는 증상은 원인 후보가 많아 막막합니다. 그런데 꺼진 모양(무징후 컷·재부팅·서서히 뜨거워지다)이 갈래를 알려줍니다. 진단 순서와 격리 방법을 정리했습니다.
  • GPU 파워 용량이 크면 전기를 더 먹나 — 용량은 상한이고, 쓰는 만큼만 나갑니다 750W 파워를 달면 전기도 750W씩 나가는 것 아닌가 하는 걱정이 커뮤니티에 반복해서 올라옵니다. 용량은 낼 수 있는 상한이지 소비량이 아닙니다. 실제 전기 사용을 정하는 것과 효율이 끼어드는 자리를 정리했습니다.
  • GPU F 붙은 CPU 사도 되나 — 아끼는 건 지금, 내장그래픽의 값은 비상시에 나옵니다 같은 CPU인데 F가 붙으면 내장그래픽이 빠지고 값이 내려갑니다. 그래픽카드를 쓸 건데 내장이 왜 필요하냐 싶지만, 내장그래픽의 진짜 쓸모는 평소가 아니라 비상시와 전환기에 있습니다. 갈림길을 정리했습니다.
  • GPU CPU·메인보드 교체하면 윈도우 다시 깔아야 하나 — 요즘은 원칙이 바뀌었습니다 보드를 바꾸면 윈도우를 재설치해야 한다는 관습이 아직 돌아다닙니다. 요즘 윈도우는 하드웨어 교체에 관대해서, CPU만 바꾸면 그대로 쓰고 보드 교체도 대개 부팅됩니다. 남는 숙제는 라이선스와 드라이버 — 판정 기준을 정리했습니다.
  • GPU 그래픽카드가 케이스에 안 들어가요 — 사기 전 확인은 세 치수입니다 케이스 스펙의 호환 길이만 믿고 샀다가 안 들어가는 사고가 실제로 흔합니다. 길이·두께(슬롯 수)·전원 커넥터 공간 세 치수를 확인하는 법과, 허용치에 딱 맞는 조합이 왜 위험한지 정리했습니다.
  • GPU 그래픽카드 온도 80도, 괜찮나 — 숫자 하나가 아니라 거동 셋으로 판정합니다 게임 중 온도를 봤다가 80도에 놀라 검색하게 됩니다. 몇 도가 정상인지는 카드마다 달라 숫자로 답할 수 없고, 판정은 온도의 거동 세 가지로 합니다. 평형·성능 유지·추세라는 기준과 개선 순서를 정리했습니다.
  • GPU 본체 먼지 청소, 얼마나 자주 — 달력이 아니라 신호를 보고 합니다 컴퓨터 청소 주기를 물으면 몇 달에 한 번이라는 답이 제각각으로 돌아옵니다. 환경마다 쌓이는 속도가 달라 숫자 답이 없는 질문이라서입니다. 청소가 필요하다는 신호 세 가지와 안전한 청소 기본기, 덜 쌓이게 하는 배치를 정리했습니다.
  • GPU 파워 팬이 안 돌아요 — 고장이 아니라 기능인 경우부터 확인합니다 새 컴퓨터의 파워 팬이 멈춰 있으면 불량인가 싶어집니다. 요즘 파워 상당수는 저부하에서 팬을 일부러 멈추는 제로팬 설계입니다. 기능인지 고장인지 가르는 판정 절차와, 그래픽카드 팬에도 같은 이야기가 적용되는 이유를 정리했습니다.
  • GPU CPU 병목 걱정 — 계산기 말고 사용률 하나로 판정합니다 조합을 정할 때마다 병목 걱정이 따라옵니다. 병목 계산기 사이트는 왜 믿을 게 못 되는지, 완벽한 균형이 왜 애초에 없는지, 내 컴퓨터의 병목을 사용률 하나로 판정하는 법을 정리했습니다.
  • GPU 모듈러 파워, 값어치 있나 — 성능이 아니라 정리와 공간의 지갑입니다 풀 모듈러, 세미 모듈러, 논 모듈러 중 뭘 사야 하는지 헷갈립니다. 성능 차이는 없고, 값어치는 케이블 정리·조립 편의·케이스 공간에서 나옵니다. 판정 기준과 케이블 혼용 금지 경고까지 정리했습니다.
  • GPU 케이스 팬은 몇 개나 — 개수보다 방향과 균형이 먼저입니다 케이스 팬을 더 달아야 하는지, 흡기·배기는 어떻게 나눠야 하는지 헷갈립니다. 팬 쇼핑 전에 확인할 것과, 몇 개부터는 효과가 급감하는 구조를 정리했습니다.
  • GPU CPU 기본 쿨러로 충분한가 — 부하와 소음, 두 기준으로 갈립니다 CPU에 딸려 오는 기본 쿨러로 버틸지, 사제 쿨러를 살지 헷갈립니다. 성능이 모자라서가 아니라 소음 때문에 바꾸는 경우가 많다는 것까지 포함해서, 판정 기준을 정리했습니다.
  • GPU 그래픽카드에서 고주파 소리 — 고장이 아닙니다, 다만 구분할 소리가 있습니다 게임이나 고부하 작업 때 그래픽카드 쪽에서 찌르르 하는 고주파음이 나면 고장부터 의심하게 됩니다. 코일노이즈의 정체와 고장 소리와의 구분법, 줄이는 방법을 정리했습니다.
  • GPU 파워는 몇 년 쓰나 — 연식이 아니라 신호로 교체합니다 파워서플라이 수명을 물으면 5년부터 15년까지 답이 갈립니다. 등급마다 다르고, 연식보다 이상 신호가 기준이기 때문입니다. 보증 기간을 수명 지표로 읽는 법과 진짜 교체 신호를 정리했습니다.
  • GPU 개인 데스크톱에 UPS — 대부분 불필요, 필요한 경우는 셋뿐입니다 정전 대비 장치가 개인 컴퓨터에도 필요할까요. 대부분은 아니고, 필요한 경우는 명확합니다. 밤새 돌리는 작업, 쓰기 중인 데이터, 잦은 정전. 용량 계산과 사인파 문제까지 정리했습니다.
  • GPU 노트북에 eGPU — 게임엔 아쉽지만 로컬 LLM엔 잘 맞는 이유 외장 그래픽 박스는 대역폭 병목 때문에 게임에서 손해를 봅니다. 그런데 로컬 LLM 추론은 구조가 달라 그 병목을 거의 안 탑니다. 왜 그런지, 무엇을 확인해야 하는지 정리했습니다.
  • GPU 그래픽카드 처짐(새그) — 지지대가 필요한 경우와 아닌 경우 요즘 상급 카드는 무거워서 끝이 처집니다. 어느 정도면 정상이고 언제 지지대가 필요한지, 수직 장착이 왜 완전한 해법이 아닌지 정리했습니다. 성능은 떨어지지 않습니다 — 문제는 다른 곳에 있습니다.
  • GPU 파워 80PLUS 등급 — 골드에 웃돈 낼 가치가 있는 경우 브론즈냐 골드냐는 취향이 아니라 나눗셈입니다. 등급이 실제로 뜻하는 것, 절감량을 kWh로 계산하는 법, 웃돈이 회수되는 조건을 정리했습니다. 로컬 LLM을 상시 돌리면 계산이 달라집니다.
  • GPU Ollama가 긴 문서를 까먹는 이유 — 컨텍스트 길이(num_ctx)와 VRAM 비용 긴 문서를 넣었는데 앞부분을 무시한다면 모델이 아니라 설정 문제입니다. Ollama의 기본 컨텍스트가 얼마인지, 어떻게 늘리는지, 늘리면 VRAM이 얼마나 더 드는지 계산으로 정리했습니다.
  • GPU 중고 그래픽카드 살 때 — 채굴 이력은 못 밝힙니다 채굴 이력은 GPU-Z로도 확인이 안 됩니다. 밝힐 수 없는 것을 추리하는 대신, 그 자리에서 잴 수 있는 것 네 가지를 정리했습니다. VRAM, 부하 온도, 아티팩트, 보증.
  • GPU AMD 라데온으로 로컬 LLM — 되긴 되는데 손이 갑니다 VRAM 규칙은 NVIDIA와 똑같습니다. 갈리는 건 하드웨어가 아니라 소프트웨어입니다. 어디서 막히는지, 이미 갖고 계신 경우와 새로 사는 경우를 갈랐습니다.
  • GPU 그래픽카드 파워 용량 — W보다 커넥터가 먼저 막습니다 카드별 TDP로 필요 용량을 계산했습니다. 다만 용량이 충분해도 12V-2x6 커넥터가 없으면 못 꽂습니다. 로컬 LLM은 게임과 부하가 달라 기준도 다릅니다.
  • GPU 로컬 LLM 전기요금 — 정말 공짜인가 전기요금만 든다고들 합니다. 얼마인지 계산했습니다. 누진 구간에 걸리면 이야기가 달라지고, 24시간 켜두면 특히 그렇습니다. 계산식과 확인처를 정리했습니다.
  • GPU 그래픽카드 두 장 — VRAM이 합쳐지나요 합쳐지지 않습니다. 나눠 올릴 수는 있지만 속도는 더해지지 않습니다. 8GB 두 장과 16GB 한 장이 왜 다른지, 두 장이 의미 있는 경우는 언제인지 정리했습니다.
  • GPU RTX 5090 32GB — 개인용 상한선입니다 32GB는 개인용 신품 그래픽카드의 천장입니다. 32B를 여유롭게 쓰는 유일한 선택지이고 70B는 여전히 안 됩니다. 575W라는 대가와 함께 정리했습니다.
  • GPU 로컬 LLM 처음이라면 — 용어 없이 읽는 시작 가이드 VRAM, 양자화, 파라미터 같은 말을 몰라도 됩니다. 내 컴퓨터로 AI를 돌릴 수 있는지, 무엇부터 확인해야 하는지 순서대로 정리했습니다.
  • GPU Ollama 설치부터 첫 대화까지 — 명령어 두 줄 로컬 LLM을 처음 돌려보는 가장 빠른 길입니다. 설치, 모델 받기, 대화까지 순서대로. 어떤 모델을 골라야 하는지도 함께 정리했습니다.
  • GPU 중고 RTX 3060 12GB — 로컬 LLM 입문에 아직 쓸 만한가 단종된 구형 카드지만 VRAM 12GB로 14B 모델이 여유롭게 돌아갑니다. 신품 5060 8GB와 비교해 어느 쪽이 맞는지, 중고로 살 때 확인할 것을 정리했습니다.
  • GPU RTX 4060으로 로컬 LLM — 8GB로 어디까지 되나 가장 흔한 입문 카드인 RTX 4060의 VRAM은 8GB입니다. 어떤 크기 모델이 쾌적하게 돌고 어디서 막히는지, 8GB의 한계선을 정리했습니다.
  • GPU RTX 5060 Ti 16GB vs RTX 5070 — VRAM이냐 속도냐 신품 중급 구간에서 가장 많이 갈리는 선택입니다. 5060 Ti는 VRAM 16GB, 5070은 대역폭 1.5배. 단종된 4060 Ti·4070을 보고 계셨다면 이 글이 대체입니다.
  • GPU RTX 5070 Ti vs 5080 — 로컬 LLM에서는 같은 카드입니다 VRAM이 둘 다 16GB이고 대역폭 차이는 7%입니다. 돌아가는 모델 크기가 완전히 같습니다. 로컬 LLM만 본다면 더 비싼 쪽을 살 이유가 없습니다.
  • GPU VRAM 8GB에서 최대한 뽑아쓰기 — 카드를 바꾸기 전에 8GB는 좁지만 쓸 수 없는 건 아닙니다. 컨텍스트를 늘려도 되는 이유, 양자화를 올리면 안 되는 이유를 계산으로 정리했습니다.
  • GPU 중고 RTX 3090 vs 신품 4070 — 로컬 LLM은 어느 쪽 로컬 LLM에서는 세대가 낮아도 VRAM이 큰 쪽이 유리합니다. 3090 24GB와 4070 12GB를 실제 기준으로 비교했습니다.
  • GPU Ollama 최소 사양 — 내 VRAM으로 몇 B 모델까지 돌아가나 로컬 LLM을 돌리기 전에 확인할 것은 GPU 이름이 아니라 VRAM입니다. VRAM 용량별로 실제 돌아가는 모델 크기를 정리했습니다.
